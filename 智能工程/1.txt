第三章 移动机器人运动学

4.1 轮式移动机器人平面运动自由度基本概念

自由度





定义：衡量轮式移动机器人平面运动的基本性能。



重要性：





体现改变机器人运行状态的能力。



必须满足实际作业需求。



需要考虑实现成本。



是机器人机构选型和设计的基础。



是机器人控制和规划算法的依据（一般来说，自由度相同的机器人可采用相同的控制和规划算法）。



约束：对于平面运动，自由度最大不能超过 3。



组成：包含瞬时自由度（移动度）、附加自由度（转向度）、综合自由度（机动度）。



相关性：与车轮的运动约束相关。

4.2 滑动约束与瞬时旋转中心 (ICR)

滑动约束





定义：对机器人运行方向的限制。



数学描述：





速度向量 \(\dot{q}\) 一定属于由投射矩阵 \(C(q)\) 构成的零空间。



零空间指在此空间中的任意一个向量 \(v\) 满足 \(C(q)v = 0\)。



对应于实际机器人上，其有可能由瞬时旋转中心（ICR）表示。

瞬时旋转中心 (ICR)





机器人瞬时运动轨迹的圆心。

4.3 移动度 (Degree of Mobility, \(\delta_m\))





定义：衡量轮式移动机器人瞬时改变机器人运行方向的能力。



数学描述：





机器人运动学是由一组独立的约束 \(C(q)\dot{q} = 0\) 构成的。



\(C(q)\) 的秩越大，说明机器人运动的约束越多。



计算公式：\(\delta_m = 3 - \text{rank}(C(q))\)。

4.4 转向度 (Degree of Steerability, \(\delta_s\))





定义：代表了机器人间接改变运行状态的能力。





在某一瞬时，一个特定的姿态代表着一个运动学约束。



改变这种姿态可带来附加的运行自由度。



代表了独立的能够转向的舵机个数。



取值范围：\(0 \le \delta_s \le 2\)。



示例：





阿克曼转向：\(\delta_s = 1\)。



双舵机：\(\delta_s = 2\)。

4.5 机动度 (Degree of Maneuverability, \(\delta_M\))





定义：描述机器人改变运动状态的综合能力（注意：不是瞬时能力）。



性质：





机动度相同的机器人，结构不一定相同。



任何机动度 \(\delta_M = 2\) 的机器人，其瞬时旋转中心必然位于一直线上。



任何机动度 \(\delta_M = 3\) 的机器人，其瞬时旋转中心可以分布于空间中的任意一点。

情形 2：\(\delta_M = 2, \delta_m = 1, \delta_s = 1\)

典型轮式机器人方案分类

根据“移动度”和“转向度”，轮式移动机器人可分为五类：

1. 全向机器人





Type (3,0)：完整约束全方位移动机器人





示例：CMU单球机器人、南开大学NKOMNI脚轮机器人、天津山石排渣麦克轮车。



Type (2,1)：非完整约束全方位移动机器人





特点：一般采用舵机加脚轮或瑞典轮的方式，十分罕见，横向平移稳定性差，不易控制。



Type (1,2)：非完整约束全方位移动机器人





示例：深圳普智联科停车机器人。

2. 非全向机器人





Type (2,0)：非完整约束移动机器人





示例：美国KIVA system双轮差速车、美国先锋机器人。



Type (1,1)：非完整约束移动机器人





示例：自动牵引车、叉车式机器人、中国玉兔号月球车、美国机遇号火星车。

移动机器人运动学的特点

运动学模型的定义





运动学模型就是构建机器人驱动（输入）和机器人空间位姿（输出）间的相互关系。

与机械臂运动学模型的区别





机械臂





本体坐标系固定在环境中



精度高



位姿通常可通过关节码盘获得



描述方式常为“码盘—位姿”的一一映射关系



移动机器人





本体坐标系随机器人运动而变化



精度较低



无法像机械臂一样直接通过内部编码器建立位置空间中的一一对应关系

移动机器人运动学模型的核心特点





无法从位置空间找到一一对应关系



更适合在速度空间中描述车轮相对运动增量与机器人运动之间的关系



因此采用微分运动学（Differential Kinematics）：





用速度空间的映射关系替代位置空间的映射关系

运动学模型的重要性

移动机器人运动学模型是以下工作的基础：





机械结构设计



控制器设计



环境感知单元设计

并且：





与车轮类型密切相关



大部分轮式移动机器人都含有非完整约束

常见车轮类型：

标准轮（Standard Wheel）

结构与自由度





轮轴垂直于轮平面



存在垂直旋转轴



车轮触地点与轮轴中心点连线构成基本几何关系

运动特性





两个自由度：





沿轮平面的滚动



沿垂直旋转轴转动



一个约束：





沿轮轴方向不能滑动



因此具有很强的指向性

分类





标准固定轮





旋转轴固定



一个自由度



标准转向轮（舵轮）





两个自由度

脚轮（Castor Wheel）

关键参数





偏心距 \(d\)：触地点到垂直旋转轴的距离

运动特性





三个自由度：





沿轮平面的滚动



沿垂直旋转轴转动



沿轮轴方向的运动



无约束，灵活性高



常用于随动轮

工程特点





调向时会对机器人底盘施加扭矩



偏心距会使转向轴承受较大压力，易损坏轴承

瑞典轮（Swedish Wheel）

运动特性





三个自由度：





沿轮轴转动：主动驱动



沿轮轴方向滚动：被动



沿垂直旋转轴转动：被动



无约束，灵活性高

使用特点





不能单独使用，至少需要 3 个及以上轮共同作用



对地面冲击大、噪音大、易损坏地面



运行震动大，对机器人本体冲击大



易损坏：一个小轮损坏，整个轮失效



成本高

特殊形式





麦克纳姆轮（Mecanum Wheel）





通过设计曲线实现连续接触地面



适合较大负载



至少需要 4 个轮共同作用



连续切换轮





最少仅需 3 个共同作用

球轮（Spherical Wheel）

运动特性





三个自由度，是真正意义上的全向轮：





沿两个正交轮轴的转动：主动驱动



沿垂直旋转轴转动：主动驱动



无约束，灵活性极高

工程特点





成本高：制造和维护成本都很高



容易积灰、磨损



可靠性差，因此极少使用

轮式机器人设计总结





轮式机器人的设计方案在绝大多数场景中最有效



至少应有 3 个轮子同时着地



机器人重心应落在车轮着地点构成的支撑三角形内，才能保证静态稳定性



四轮结构可提升系统稳定性，适合高速行驶





三轮车更容易侧翻



但四轮通常需要合适的悬架系统



轮子类型需要根据实际应用需求选择



轮子越大，通过性越好，可跨越更大障碍，但需要更大扭矩

轮式移动机器人运动学建模

空间描述

大部分轮式移动机器人都具有非完整约束，因此：





无法从位置空间找到一一对应关系



应采用微分运动学描述

平面内常用的空间描述包括：





惯性参考坐标系 \(I\)（Inertial Reference Frame）



机器人参考坐标系 \(R\)（Robot Reference Frame）



机器人位姿（Pose: Position and Orientation）



笛卡尔坐标系采用右手法则

空间变换





机器人作业目标及控制指令一般在惯性参考坐标系下描述



传感器测得的环境信息一般也在惯性参考坐标系下描述



机器人控制器中的误差输入及控制指令通常在机器人参考坐标系下描述

速度变换关系可写为：

\[ \dot{\boldsymbol{\xi}}_{R} = R(\theta)\,\dot{\boldsymbol{\xi}}_{I} \]

其中：





\(R(\theta)\) 为单位正交阵（旋转矩阵）



这里只讨论速度空间的关系，因此不涉及位置的平移变换

运动学模型的目标

已知：





机器人轮子转速 \(\dot{\phi}\)



舵机转角 \(\beta\)



舵机角速度 \(\dot{\beta}\)



机器人几何尺寸

求：





机器人坐标系下的速度

对应两个问题：





正运动学：由轮速、转角等输入求机器人速度



逆运动学：由期望机器人速度求轮速和转角等控制量

两轮差速机器人正运动学建模

设机器人安装两个半径为 \(r\) 的车轮，两轮中心距机器人中心为 \(l\)，左右轮线速度分别为 \(v_l\)、\(v_r\)。

ICR 法建模思路

建模过程





确定系统输入



根据作业要求确定惯性参考坐标系，确定输出



确定机器人参考坐标系



建立坐标系变换关系\[ \dot{\boldsymbol{\xi}}_{R} = R(\theta)\,\dot{\boldsymbol{\xi}}_{I} \]



将机器人视为刚体





各点间相对距离不变



各点角速度相同



利用固定标准轮的轮轴方向运动约束



设瞬时旋转中心 ICR 到机器人坐标系原点的距离为 \(R\)，已知轮子中心距机器人原点为 \(l\)



结合几何关系求解机器人速度与角速度

关键结论





瞬时旋转中心（ICR）即瞬时曲率中心



利用轮速差可确定机器人绕 ICR 的瞬时转动状态



差速机器人满足：





\(\dot{y}_R = 0\)

ICR 法特点

原理





标准轮提供沿车轮轴线方向的滑动约束



刚体各点角速度相同

优点





直观



对标准轮建模较容易

缺点





一事一议，不具备通用性



仅适用于标准轮建模

基于约束的移动机器人建模方法

前提假设

轮式机器人运动学约束建模通常基于以下假设：





机器人在水平面上运动



车轮与地面为点接触



车轮不变形



纯滚动：





接触点无滑动速度



无滑动、无打滑



舵机转轴与地面垂直



轮子安装在刚体表面上

各类车轮的约束建模

固定标准轮（Fixed Standard Wheel）

变量说明





机器人速度状态：\(\dot{x}_R,\dot{y}_R,\dot{\theta}_R\)



轮线速度：\[ v = r\dot{\phi} \]



几何参数：\(l,\alpha,\beta\)

注意





\(\alpha,\beta\) 的零点位置与 \(v\) 的朝向有关

约束





纯滚动约束



无滑动约束：沿轮轴方向无运动

转向标准轮（Steering Standard Wheel）





与固定标准轮类似，但转向角 \(\beta\) 为时间变量 \(\beta(t)\)

约束





纯滚动约束



无滑动约束

标准轮运动约束总结





标准轮均对机器人本体提供两个运动约束：





轮平面的滚动约束



轮轴方向的滑动约束



标准转向轮能够提供额外的转向能力，从而提供改变机器人运动状态的可能



对于主动驱动轮，需要同时考虑滚动和滑动约束



对于随动轮（无驱动、跟随机器人本体运动），仅需考虑滑动约束

脚轮（Castor Wheel）约束建模

特点





由于存在偏心距 \(d\)，车体速度在车轮轴线方向的投影通过角速度形式作用到轮上



车轮本身具有两个自由度：





沿轮平面滚动



沿车轮触地点与轮心连线的转动

约束





触地点滑动约束：沿车轮轴线方向速度为 0



若满足滑动约束，则车轮触地点速度满足：\[ v_w = 0 \]

关键几何/运动关系





连杆相对于惯性系的角速度为：\[ \dot{\theta}_R + \dot{\beta} \]



连杆的 ICR 必须位于触地点



为满足滑动约束，A 点处与连杆垂直方向的合成速度产生的角速度，必须等于连接杆相对于惯性系的角速度



旋转方向需要统一

脚轮运动约束总结





脚轮由于安装偏心结构，可通过调节车轮相对地面的旋转角速度，为机器人本体提供各个方向上的运动速度



对于主动驱动脚轮，需要同时考虑两个方面的约束，并通过控制 \(\dot{\beta}\) 实现全方位运动



对于随动脚轮，不会给机器人本体带来运动约束，因此可视为全向运动轮

麦克纳姆轮建模

变量与说明





轮线速度：\[ v = r\dot{\phi} \]



几何角参数：\(\alpha,\beta,\gamma\)

注意





\(\alpha,\beta,\gamma\) 的零点位置与 \(v\) 的朝向有关



\(\gamma = 0\) 时，为 \(90^\circ\) 瑞典轮



\(\gamma = 45^\circ\) 时，为麦克纳姆轮



对触地车轮建立约束时，速度投影应投到小轮方向上

约束方程





纯滚动约束

\[ \begin{bmatrix} \cos(\alpha+\beta+\gamma) & \sin(\alpha+\beta+\gamma) & l\sin(\beta+\gamma) \end{bmatrix} R(\theta)\dot{\boldsymbol{\xi}}_{I} - r\dot{\phi}\sin\gamma - r_{sw}\dot{\phi}_{sw}=0 \]



无滑动约束

\[ \begin{bmatrix} \sin(\alpha+\beta+\gamma) & -\cos(\alpha+\beta+\gamma) & -l\cos(\beta+\gamma) \end{bmatrix} R(\theta)\dot{\boldsymbol{\xi}}_{I} - r\dot{\phi}\cos\gamma = 0 \]

解释





麦克纳姆轮先通过控制车轮转速来满足小轮滑动约束



其滚动约束可由随动小轮 \(r_{sw}\dot{\phi}_{sw}\) 保证



麦轮为全向轮，因此当麦轮作为随动轮时，可不考虑运动约束

瑞典轮总结





三个自由度，对称排布：





沿轮轴转动：主动驱动



沿轮轴滚动：被动



沿垂直旋转轴转动：被动

基于约束的整体运动学建模

一般建模原则

给定一个包含 \(M\) 个车轮的机器人：





每个车轮都会给机器人本体提供 0 个或多个运动约束



驱动轮需要考虑：





滚动约束



滑动约束



随动轮仅需考虑滑动约束





只有标准轮作为随动轮时才需考虑滑动约束



所有车轮约束的合成构成机器人整体的运动学约束



无论是滚动约束还是滑动约束，都只考虑独立约束



平面运动下，机器人输出状态为三维向量，因此最多只有 3 个独立约束

滚动约束方程

对于包含 \(N\) 个标准轮的机器人，其中：





\(N_f\)：固定标准轮数量



\(N_s\)：转向标准轮数量

其滚动约束可组织成矩阵形式。并有：





一个常数矩阵



一个约束矩阵



一个以轮径 \(r\) 为元素的对角矩阵

滑动约束方程

同样对于包含 \(N\) 个标准轮的机器人：





滑动约束也可写成矩阵形式



其中包含：





常数矩阵



约束矩阵

综合约束





将滚动约束与滑动约束融合，可得到机器人整体的运动学约束方程

ICR 法结果

\[ R=\frac{L_2}{\cos\beta} \] \[ \dot{y}_R=0 \] \[ \dot{\theta}_R=-\frac{r\dot{\phi}}{L_2}\cos\beta \] \[ \dot{\boldsymbol{\xi}}_R= \begin{bmatrix} \dot{x}_R\\ \dot{y}_R\\ \dot{\theta}_R \end{bmatrix} = r\dot{\phi} \begin{bmatrix} \sin\beta\\ 0\\ -\dfrac{\cos\beta}{L_2} \end{bmatrix} \]

约束法

主动轮





滚动约束：

\[ \begin{bmatrix} \sin\beta & -\cos\beta & -L_2\cos\beta \end{bmatrix} R(\theta)\dot{\boldsymbol{\xi}}_I-r\dot{\phi}=0 \]



滑动约束：

\[ \begin{bmatrix} \cos\beta & \sin\beta & L_2\sin\beta \end{bmatrix} R(\theta)\dot{\boldsymbol{\xi}}_I=0 \]

随动轮





滑动约束：\[ \begin{bmatrix} \cos\frac{\pi}{2} & \sin\frac{\pi}{2} & l\sin\pi \end{bmatrix} R(\theta)\dot{\boldsymbol{\xi}}_I=0 \] 即\[ \begin{bmatrix} 0 & 1 & 0 \end{bmatrix} R(\theta)\dot{\boldsymbol{\xi}}_I=0 \Rightarrow \dot{y}_R=0 \]

联立得到

\[ \dot{x}_R\sin\beta-\dot{y}_R\cos\beta-\dot{\theta}_R L_2\cos\beta=r\dot{\phi} \] \[ \dot{x}_R\cos\beta-\dot{y}_R\sin\beta+\dot{\theta}_R L_2\sin\beta=0 \]

结合 \(\dot{y}_R=0\) 可进一步解得机器人速度表达式。

进一步说明





可通过滑动约束来寻找 ICR



需要思考：滑动约束是谁提供的？

1. 移动机器人运动控制基本概念





定义：不考虑系统的动态特性，仅为运动学控制（即对位置、速度等进行控制）。



运动控制目标：





以指定姿态到达指定工作位置。



跟随给定路线。



跟随给定的轨迹。



核心任务：构建从误差到输入的映射模型。





误差：任务（给定）和环境感知（反馈）均在作业空间（惯性参考坐标系）下描述。

控制问题分类：





定点（镇定）控制

非完整系统：由于滑动约束的存在，大部分移动机器人是典型的非完整系统，使得控制目标无法独立完成（如侧向偏差与姿态偏差耦合）。



非线性：系统存在强非线性特性，控制器设计较为复杂。



控制律限制：对于非完整约束机器人，不存在连续时不变（静态）反馈控制律使其达到目标位姿。



难度对比：镇定比跟踪更难。

3. 移动机器人运动控制器分类





定点（镇定）控制：





无模型定点控制



基于模型的定点控制



跟踪控制：





路径跟踪控制：





无模型路径跟踪控制



基于模型的路径跟踪控制



轨迹跟踪控制：





无模型轨迹跟踪控制



基于模型的轨迹跟踪控制

4. 开环控制





方法：将运动轨迹分割成事先定义好的构形（如直线和圆弧）。



缺点：





很难事先定义若干合适的轨迹。



受机器人速度加速度约束。



如果环境动态变化，无法自适应调整轨迹。



所得轨迹一般不光滑。

根据作业需求定义系统开环误差信号。



误差信号描述变换：惯性参考坐标系 \(\to\) 机器人参考坐标系。



基于机器人模型，构建闭环系统误差模型。



控制器设计。



稳定性分析。



仿真实验。



实际实验。

6. 定点控制器设计

6.1 问题描述





令 \(q_r = [x_r, y_r, \theta_r]^T \in \mathbb{R}^3\) 为参考状态。



令 \(\tilde{q} = [\tilde{x}, \tilde{y}, \tilde{\theta}]^T \in \mathbb{R}^3\) 为开环误差。



将误差信号从惯性参考坐标系变换为机器人参考坐标系。

6.2 差速机器人为例





PID控制器：





考虑差速机器人滑动约束 \(\dot{y}_R = 0\)。



求取闭环系统误差模型。



设计无模型闭环控制器。



非线性控制器：





考虑系统模型设计控制器。



带入闭环系统模型。

6.3 基于极坐标变换的控制器





闭环误差模型：





将系统开环误差在极坐标下转换为 \((\rho, \alpha, \beta)\)。



差速机器人滑动约束 \(\dot{y}_R = 0\)。



其中 \(v_1\) 为线速度，\(v_2\) 为角速度。



线性控制器：





设计线性控制器。



稳定性分析：





系统中非线性项由参数 \(\alpha\) 带来，若 \(\alpha\) 接近于 0 时，系统可视为线性。



若矩阵 \(A\) 的所有特征根实部均为负数，则系统指数性收敛。



结论：局部指数性稳定，非全局稳定。



非线性控制器：





设计非线性控制器。



稳定性分析：





设非负李雅普诺夫函数。



结论：全局渐近稳定。

7. 轨迹跟踪控制器设计

7.1 问题描述





控制目标：设计控制器驱动移动机器人从当前状态（位置和姿态）跟踪一个给定的轨迹。



系统状态：\(q = [x, y, \theta]^T\)。



系统控制输入：\(u = [v, \omega]^T\)。



运动学模型（差速移动机器人，纯滚动无滑动）：\[ \begin{cases} \dot{x} = v \cos \theta \\ \dot{y} = v \sin \theta \\ \dot{\theta} = \omega \end{cases} \] 其中 \(v_r, \omega_r\) 表示给定线速度和角速度。



误差定义：令 \(q_r\) 为参考状态，\(\tilde{q}\) 为开环误差。

7.2 控制器设计





基于可逆变换得到辅助误差信号。



对辅助误差信号求导，并代入控制器。



设计控制器形式，代入开环误差中。

8. 路径跟踪控制器设计

8.1 问题描述





系统开环误差信号：





令 \(q_r(s) = [x_{rs}, y_{rs}, \theta_{rs}]^T \in \mathbb{R}^3\) 为参考路径。



令 \(\tilde{q} = [x, y, \theta]^T \in \mathbb{R}^3\) 为开环误差。



注意：\(s \in [0,1]\)，为路径参考变量。



控制目标：设计控制器 \(u = f(\tilde{q})\)，使机器人跟踪给定路径。



与轨迹跟踪的区别：路径跟踪没有严格的时间要求。

8.2 研究意义





安全性：防止碰撞，机器人必须严格按照路径运行。



检测手段约束：无法获得轨迹跟踪误差。



应用需求：没有严格的时间要求。



机器人系统性能约束：无法严格跟踪轨迹。

8.3 控制器设计





定义系统开环误差信号。



误差信号描述变换。



基于机器人模型，构建闭环系统误差模型。



控制器设计：





设计包含参数 \(b\) 的控制器。



稳定性分析：系统指数性收敛。



参数 \(b\) 的作用：对应于向前看的距离。





\(b\) 值大：机器人跟踪速度快，但是轨迹跟踪精度低。



\(b\) 值小：机器人跟踪速度慢，但是轨迹跟踪精度高。

9. 移动机器人运动控制总结





机动度相同的移动机器人平台可使用相同的控制方法。



控制器选择需要确定其使用的反馈信号是否可得。



目前还没有一个控制方法可以很好的同时实现定点控制和跟踪控制，往往需要进行切换控制（注意切换过程中的输入连续性）。



受执行单元的性能约束，控制输入需要进行合理的限幅。



需要根据控制器原理，注意控制参数的调节顺序。



控制参数调节时，注意分析实验过程中的各个运行曲线的关联性，并于物理系统进行对应。



传感系统与机器人本体间、机器人模型参数等的标定对控制精度影响巨大。



注意：控制只能解决很小一部分问题，不要过分依赖或信任控制系统的能力。


第五章 移动机器人感知技术 5：蒙特卡洛定位算法 (MCL)

1. 蒙特卡洛方法基本思想

1.1 何为蒙特卡洛方法





提出者：冯·诺伊曼、乌拉姆等人。



定义：一类基于概率的方法的统称。



工作原理：





不断抽样。



逐渐逼近。



优点：非常通用，可以解决十分复杂的问题。



缺点：收敛速度慢，不精确。



应用实例：蒙特卡洛搜索树——AlphaGo。

1.2 分布函数拟合





任意概率分布都可以通过样本（粒子：Particle）分布来描述。



某一区间样本越多，则对应的发生概率越高。



可有效处理非高斯分布以及各种复杂分布。

1.3 已知概率分布求取粒子分布——采样排除法

假设 \(f(x) < 1\) 对所有 \(x\) 成立：





从均匀分布中采样 \(x\)。



从 \([0,1]\) 中采样 \(c\)。



如果 \(f(x) > c\)，保留样本；否则拒绝样本。

1.4 未知概率分布求取粒子分布——基于重要性的重采样原理





核心思想：使用不同的分布 \(g\)（提议分布，Proposal distribution）来生成来自 \(f\)（目标分布，Target distribution）的样本。



重要性权重：引入权重 \(w\) 来衡量 \(g\) 和 \(f\) 之间的差异，公式为 \(w = f/g\)。



重采样步骤：





重要性评估：计算重要性指标 \(\omega = f/g\) 以更新概率分布。



权重归一化：\[ \bar{\omega}_i^m = \frac{\bar{\omega}_i^{fg}}{\sum_{i=1}^{N} \bar{\omega}_i^{fg}} \]



重采样：利用更新后的概率分布进行重采样，得到新的粒子集。

2. 蒙特卡洛定位算法 (MCL)

2.1 算法定义与输入输出





目标：给定环境地图，确定机器人在环境中的位姿。



输入：





上一时刻的信念 \(X_{t-1} = \{x_{t-1}^1, x_{t-1}^2, \dots, x_{t-1}^M\}\)



执行指令 \(u_t\)



传感器数据 \(z_t\)



输出：新的信念 \(X_t\)。

2.2 机器人定位问题分类





全局定位。



局部定位（位置跟随、里程计）：





ICP算法：局部收敛，易陷于局部最优，匹配错误。



卡尔曼滤波：收敛性受初始状态精度制约。



机器人绑架问题。



定位错误判断与恢复。

2.3 2D 定位示例





目标分布：\(p(c|z_1, z_2, z_3)\)。



提议分布：\(p(c|z_1)p(\alpha|z_2)p(c|z_3)\)。



重要性权重 \(w_i\)：\[ w_i = \frac{p(c|z_1, z_2, z_3)}{p(c|z_1)p(\alpha|z_2)p(c|z_3)} \] 其中 \(k \neq i\) 表示在当前样本（粒子）下观测除 \(z_i\) 外其他特征的可能性。

2.4 算法流程





初始化：从 \(X_{t-1}\) 的分布开始。



预测步：基于运动模型更新并进行简单采样。



修正步：通过传感器模型计算权重（重要性评估）。



重采样：基于归一化权重进行重采样。



输出：获得 \(X_t\) 的分布。

2.5 重采样方法





幸运转盘：





根据权重大小分配面积大小。



面积越大，被抽到的次数（概率）越高。



重采样效果：





点集的分布发生变化，更加集中于权重高的部分。



重采样后的点集权重相同，但分布密度不同。

2.6 1D 定位示例步骤





Step \(t=0\)：





初始化均匀分布粒子。



传感器更新（检测到门），分配权重。



重采样，在权重高的粒子周围生成新粒子。



Step \(t=1\)：





运动更新（向右移动 + 噪声）。



传感器更新（未检测到门），分配权重。



重采样。



Step \(t=2\)：





运动更新（向左移动 + 噪声）。



传感器更新（检测到门），分配权重。



重采样。

2.7 移动机器人运动模型





采用二阶 Runge-Kutta 法。

2.8 激光雷达观测误差模型——物理模型





激光雷达传感器测量误差：包含随机噪声，一般服从高斯分布（以真实距离为均值）。



没有检测到障碍物：返回激光雷达最大测距距离。



随机错误：返回错误的距离值。



模型特点：基于光束的物理反射特性。

2.9 激光雷达观测模型——Likelihood Field





原理：





将激光束末端投影到地图中。



计算投影点距离地图上最近障碍物点的距离。



以最近障碍物点作为均值，激光测距偏差作为方差构建高斯分布。



可离线生成可能域地图。



优点：





在线计算量小。



平滑性好，可确保算法收敛。



更加符合实际情况。



缺点：





没有明确的物理意义。



仅适用于相对静态的环境。

2.10 激光定位算法仿真实验





初始均匀分布。



机器人运动通过里程计模型更新粒子分布。



在当前状态下进行观测，进行重要性评估。



依据重要性进行重采样更新粒子分布。

2.11 蒙特卡洛 (粒子滤波) 算法总结





优点：





可解决大范围全局定位问题。



可以适用于多种分布模型。



计算简单。



缺点：





当粒子数量过大时，占用大量内存，计算效率低。



位置确定后，大量粒子冗余；但在大地图下少量粒子又易导致发散。



无法判断机器人绑架问题（定位错误问题）。

3. 自适应蒙特卡洛定位算法 (AMCL)

3.1 算法改进点





自适应体现：





解决机器人绑架问题：当粒子平均分数突然降低（正确粒子被抛弃）时，在全局重新撒入随机粒子。



解决粒子数固定问题：当粒子集中时（定位已收敛），减少粒子数量以提高效率。



解决方法：





采用 KLD 采样（Kullback-Leibler Divergence，库尔贝克-莱布勒散度）。



核心思想：根据基于采样近似质量的统计界限来确定粒子数量。以概率 \(1-\sigma\) 确保真实后验概率与采样近似分布之间的差异小于 \(\varepsilon\)。



实际应用：在栅格地图中统计粒子占据的栅格数。占据栅格多（粒子分散），允许粒子数上限高；占据栅格少（粒子集中），降低上限。

3.2 AMCL 算法与 MCL 算法区别





权重评估机制：





引入长期指数滤波器衰减率 \(\alpha_{slow}\) 和短期指数滤波器衰减率 \(\alpha_{fast}\)（ROS 中默认取 0.001 和 0.1）。



计算长期重要性指数似然评价估计 \(w_{slow}\) 和短期重要性指数似然评价估计 \(w_{fast}\)。



逻辑判断：





机器人绑架/定位错误：粒子平均权重 \(w_{avg}\) 下降，导致 \(w_{slow} > w_{fast}\)，算法将按一定概率往粒子集里注入随机粒子。



粒子聚集/定位成功：\(w_{slow} < w_{fast}\)，此时不再添加随机粒子，而是从原先的粒子集中筛选权重较大的粒子。

机器人地图的基本概念

地图的作用





地图：环境信息的一种表达方法，是移动机器人定位与导航的基础。



定位：





通过环境感知信息与地图信息的匹配，确定移动机器人在环境中的位置。



导航规划：





根据地图中记录的连通域信息和障碍物位置，规划机器人从当前点到目标点的可行路径。

地图表示方法的要求

地图表示法需要具备以下功能：





支撑机器人完成特定任务，如定位、导航、规划。



能够方便地加入新的信息并更新地图。



便于计算机存储与处理。

常用地图表示法





点云地图



栅格地图



特征地图



拓扑地图



点云地图

概念





点云地图：直接由占用空间的点集合表示的地图。



数学描述：\[ P = \{p_1, p_2, \cdots, p_n\} \]



点可表示为：





二维点：\(\,p_i = (x_i, y_i)\)



三维点：\(\,p_i = (x_i, y_i, z_i)\)

构建方法





机器人在不同位姿下采集局部点云。



将局部坐标系 \(\{L\}\) 下的点，依据机器人位姿变换到世界坐标系 \(\{W\}\) 下。



多次观测拼接后形成整体点云地图。

优点





可以完全表示环境三维信息。



所构建地图不需要预先定义尺寸。

缺点





存储要求高：16线 3D 激光雷达点云数据可达约 30 万点/秒。



存在检测盲区和空洞。



不能单凭点的占用判断空间的占用与连通状态，需要进一步处理才能得到导航所需地图（如地面）。



通用性差：不同机器人或激光雷达因高度、角度不同，通常需要重新构建地图。

应用说明





面向工业应用时，常使用路标地图等更适配的表达形式。



栅格地图

基本概念





平面栅格地图：将连续空间分解为一系列离散栅格，每个栅格具有描述其占用属性的值。

栅格属性





用于定位：





采用 \(0 \sim 1\) 的值，表示该栅格被占用的概率。



用于导航：





采用 0 或 1，表示该栅格是否可通行。

构建方法





空间栅格化





栅格大小可根据允许误差大小确定。



占用概率建模





在概率框架下，以激光测量数据为条件估计栅格占用概率。



设激光数据为 \(s_1,s_2,\cdots,s_n\)，第 \(i\) 个栅格为 \(m_i\)，则关注：

 \[ p(m_i \mid s_1,s_2,\cdots,s_n) \]



静态量的二元估计





采用几率对数形式的二元贝叶斯滤波进行求解。

几率与几率对数





几率：\[ \frac{p(m_i \mid s_1,s_2,\cdots,s_n)}{p(\bar{m}_i \mid s_1,s_2,\cdots,s_n)} \]



几率对数定义：\[ l_i = \log \frac{p(m_i \mid s_1,s_2,\cdots,s_n)}{p(\bar{m}_i \mid s_1,s_2,\cdots,s_n)} \]

贝叶斯递推





贝叶斯公式：\[ p(a\mid b)=\frac{p(a)p(b\mid a)}{p(b)} \]



若每次激光测量独立，则：\[ p(m_i \mid s_1,\cdots,s_n) = \frac{p(s_n\mid m_i)\,p(m_i\mid s_1,\cdots,s_{n-1})}{p(s_n)} \]



转换为几率对数递推形式：\[ l_{i,n} = \log \frac{p(m_i\mid s_n)}{p(\bar{m}_i\mid s_n)} + l_0 + l_{i,n-1} \] 其中：\[ l_0 = \log \frac{p(\bar{m}_i)}{p(m_i)} \]



若栅格 \(i\) 的占用情况未知，且 \(p(m_i)=0.5\)，则：\[ l_0 = 0 \]

激光逆传感器模型





根据障碍物距离测量数据 \((\rho_i,\theta_i)\)，可基于测距仪的射线模型估计栅格单元的占用概率。



栅格占用概率可写为：\[ p(m_i\mid s_n)=1-E_rE_\omega \]



其中距离误差项与角度误差项通常分别建模为高斯形式：\[ E_r = 1-k_r \exp\left(-\frac{(\omega_i-r_i)^2}{\sigma_r^2}\right) \] \[ E_\omega = 1-k_\omega \exp\left(-\frac{(\varepsilon_i-\vartheta)^2}{\sigma_\vartheta^2}\right) \]

优点





可以详细描述环境信息。



易于机器人进行定位与路径规划。

缺点





存储要求高：随着栅格数量增加和环境扩大，所需内存与维护时间迅速增长。



三维栅格扩展

2.5 维占用栅格地图





用于描述三维空间的一种方式，典型应用如 NASA 火星车。



高度图：





在每个栅格上增加一个属性，表示该栅格上障碍物高度估计信息。



注意：记录的是该栅格上障碍物最高部分的高度。



问题：





可能存在虚拟障碍物问题。

扩展高度图表示法





对栅格进行识别，确定栅格是立体结构还是包含空隙。



检查单元对应所有数据点的高度方差。



但每个单元仍只能表示 1 层信息。

三维占用栅格地图（体素地图，Voxel Map）





将空间分解为大小相同的正方体（Voxel）。



每个正方体描述对应位置是否被占用。



特点：





原理简单



扩展性强



占用大量存储空间

多分辨率地图





普通栅格地图的特点：





空间占用率高



计算复杂度高



存储具有稀疏特性



多分辨率地图：





常采用八叉树表示。



存储效率高。



特征地图（语义地图）

特点





连续线性地图



连续多边形地图



空间占用效率高



定位精度高



拓扑地图

概念





将环境表示为带节点和连接线的拓扑结构图：





节点表示环境中的重要位置点



边表示节点间连接关系

特点





地铁、公交线路图属于典型拓扑地图。



非常方便进行导航和路径规划。



可由点云地图、栅格地图、特征地图进一步抽象得到。



由于信息高度抽象，难以用于机器人精确可靠的定位。



SLAM 算法基本思想

定位（Localization）





根据环境地图、机器人的运动序列和观测序列，确定机器人在地图中的位置与姿态。



误差来源：





全局定位的初始误差



局部定位中的观测噪声



前提：





地图已知



估计目标可表示为：\[ E\!\left[X_t \mid Z_t,U_{t-1},m\right] \]

建图（Mapping）





根据观测序列以及机器人位置和姿态，确定环境信息。



误差来源：





观测噪声



前提：





机器人的位置与姿态已知



估计目标可表示为：\[ E\!\left[m \mid Z_t,X_t\right] \]

SLAM 的定义





SLAM（Simultaneous Localization and Mapping）：





根据机器人的运动序列、观测序列，同时估计机器人的位置与姿态以及环境地图。



估计目标：\[ E\!\left[X_t,m \mid Z_t,U_{t-1}\right] \]

核心难点





SLAM 是“先有鸡还是先有蛋”的问题：





建图需要机器人位姿信息



机器人定位需要地图信息



位姿估计误差、观测误差与地图构建误差会相互叠加，容易发散。



SLAM 是实现机器人自主导航的基础。

发展历程





1986 年 ICRA 会议提出用概率方法求解 SLAM，当时认为地图构建与机器人状态误差不可收敛。



1996 年证明 SLAM 可以收敛，并给出收敛条件。



2001 年 TRO 论文成为 SLAM 奠基性工作。

收敛原因





路标测量误差具有一致性：





每次测量时，两路标之间的相对关系较为准确。



随着观测增加，路标间关联强度增强，地图估计更准确。

数据关联与闭环检测





数据关联是 SLAM 收敛的关键，错误匹配会导致算法发散。



闭环检测：





当机器人回到以前到过的位置时，需要与之前观测建立正确的数据关联。



这种关联称为闭环检测。



可有效降低估计不确定性。



SLAM 算法分类

基于滤波的 SLAM





EKF-SLAM（卡尔曼滤波）



FastSLAM（粒子滤波）——GMapping

基于优化的 SLAM





基于图优化的 SLAM——g2o

基于滤波方法的 SLAM 算法

3.1 EKF-SLAM

基本特点





第一个 SLAM 算法，提出于 1986 年。



主要面向特征地图，尤其是路标特征地图。



采用 maximum likelihood 进行数据关联。



假设特征彼此清晰可分。



假设机器人运动噪声和观测噪声满足高斯分布。



以机器人初始位姿为地图坐标系原点。



与 EKF 机器人定位问题类似，但状态维度显著增加。

状态表示





SLAM 待估计状态：\[ x_t \in \mathbb{R}^{3+2n} \]



状态向量形式：\[ x_t= \begin{bmatrix} X_R\\ M_1\\ M_2\\ \vdots\\ M_n \end{bmatrix} \] 其中：





\(X_R\)：机器人状态



\(M_i\)：第 \(i\) 个路标位置



协方差矩阵包含：





机器人自身不确定性



路标自身不确定性



机器人与路标之间相关性



路标之间相关性

初始状态





初始机器人位姿可设为原点。



初始协方差中：





机器人状态协方差已知



路标尚未观测时可设为未初始化或大不确定性



机器人与路标、路标与路标之间的相关项初始为 0



EKF-SLAM 算法流程

总体步骤





State Prediction：基于运动模型进行状态预测



Measurement Prediction：基于观测模型进行观测预测



Observation：获得当前观测



Data Association：建立预测观测与当前观测的数据关联



Update：利用 Kalman 增益更新状态



Integration of New Landmark：将新路标加入地图



EKF-SLAM 的运动估计

预测形式





预测状态：\[ \bar{x}_t = f(x_{t-1},u_{t-1}) \]



对机器人部分：\[ \bar{X}_{Rt}=f(X_{R,t-1},u_{t-1}) \]



地图中的路标在预测阶段通常保持不变。

协方差预测





协方差递推：\[ \bar{\Sigma}_t = F_t \Sigma_{t-1} F_t^\top + Q_t \]



其中：





\(F_t\)：运动模型对状态的雅可比



\(Q_t\)：过程噪声协方差

里程计模型





机器人位姿更新由线速度、角速度等输入决定。



EKF-SLAM 中仅机器人位姿部分受控制量影响，路标状态不受运动输入直接影响。

误差传导





通过运动模型雅可比矩阵实现里程计误差向状态协方差的传播。



地图部分的误差通过与机器人状态的相关项间接更新。



EKF-SLAM 的观测估计与更新

观测估计





根据预测的机器人位姿，预测各路标在传感器中的观测：\[ \hat{Z}_t = h(\bar{X}_{Rt}) \]



每个路标观测通常可视为独立。

数据关联





将预测观测与当前实际观测进行匹配。



正确的数据关联是 EKF-SLAM 成功的关键。

状态更新





基于观测残差与 Kalman 增益更新机器人位姿和地图路标位置。



同时更新协方差矩阵，使状态之间的相关性得到修正。



激光观测模型与坐标变换

激光测量





在机器人坐标系中，单个观测通常表示为：\[ z_t^i = [r_t^i,\omega_t^i]^\top \] 其中：





\(r_t^i\)：距离



\(\omega_t^i\)：方位角

观测投影





需要将机器人坐标系下的测量数据投影到世界坐标系。



观测方程 \(h(\bar{x}_t)\) 可转化为机器人位姿与测量共同决定的世界坐标位置关系。

观测雅可比





观测更新时需构造观测雅可比矩阵 \(H_t\)。



新特征的加入

新路标初始化





当观测到尚未存在于地图中的新特征 \(m_{n+1}\) 时，需要将其加入状态向量。



从机器人坐标系转换到世界坐标系：\[ m_{n+1} = f(X_R,z_{n+1}) \]

新路标协方差





新路标的不确定性由机器人位姿不确定性与测量不确定性共同决定：\[ \Sigma_{m_{n+1}} = F_R \Sigma_{X_R} F_R^\top + F_Z \Sigma_{z_{n+1}} F_Z^\top \]



新路标与已有路标、机器人之间也会建立相关协方差项，例如：\[ \Sigma_{m_{n+1}m_i}=F_R\Sigma_{X_Rm_i} \] \[ \Sigma_{m_{n+1}X_R}=F_R\Sigma_{X_R} \]



EKF-SLAM 仿真与实验效果

轨迹说明





蓝色：真实轨迹



红色：EKF-SLAM 估计轨迹



绿色：里程计估计轨迹

现象





与仅依赖里程计相比，EKF-SLAM 能更好地估计机器人轨迹并同步修正地图。



EKF-SLAM 的问题与局限

主要问题





所有路标之间为全连接。



计算复杂度高，难以用于大场景地图。



要求高斯分布，因此只能处理单峰假设。



一旦数据关联错误，容易发散。



仅适用于人工路标等特征清晰场景。



只能使用点云地图或特征地图，难以直接使用栅格地图。

回环问题





回环识别：识别已建图区域。



难点包括：





数据关联具有高度模糊性



环境可能存在对称性



一旦发生回环闭合，不确定性会迅速收缩；但若闭合错误，也可能造成严重误差。



EKF-SLAM 总结

核心思想





用多变量高斯分布表达机器人位姿和路标估计。



通过高斯协方差矩阵描述状态之间的高度互相关性。

致命缺点





计算复杂度高（quadratic complexity）





协方差矩阵规模为：

 \[ (2N+3)\times(2N+3) \]





包含位姿与路标之间的全部互相关信息。



只要观测到一个路标，整个协方差矩阵都要更新。



在包含大量路标的复杂自然环境中，难以满足实时性要求。



数据关联是单假设的（single-hypothesis data association）





每次将观测与“最可能”的路标进行关联。



只要少量错误关联，就可能导致算法发散。



虽然可以通过同时考虑多个观测值改善，但只是以更高计算代价换取一定鲁棒性，无法根本解决潜在的数据关联问题。



如果缺乏足够信息进行纠正，最终仍可能发散。

3.2 FastSLAM

基本概念





提出者：Montemerlo等人 (2003)。



核心思想：将粒子滤波器与EKF集成。





使用改进的粒子滤波器估计机器人路径的后验分布，机器人的位姿通过粒子分布表示。



每个粒子代表一条可能的运动路径，利用观测信息计算权重以评价路径质量。



路标位置使用EKF估计，即每个粒子拥有 \(N\) 个独立的EKF（2维），用于在给定路径估计条件下估计 \(N\) 个路标的位置。



条件独立性：在机器人路径已知的情况下，路标位置的估计相对独立。

3.2.1 Rao-Blackwellization Particle Filter (RBPF)

粒子维度问题





AMCL算法中，粒子维度为3维：\([x, y, \theta]\)。



FastSLAM中，若直接对状态进行采样，粒子维度为 \(3t + 2N\) 维：\[ x = (x_{1:t}, l_{1,x}, l_{1,y}, l_{2,x}, l_{2,y}, \dots, l_{N,x}, l_{N,y})^T \]



粒子滤波在低维空间有效，高维空间需要覆盖大量样本，因此需要降维。

粒子降维的核心思想





利用粒子对机器人路径 \(x_{1:t}\) 进行建模（即对路径的假设）。



对于每一个粒子（即每一条假设的路径），可以独立地计算一套路标地图 \(l_{1,x}, l_{1,y}, \dots\)。

Rao-Blackwell 定理与因式分解





利用变量间依赖关系进行因式分解。如果可以得到 \(p(b|a)\) 的封闭解，可以用 \(p(a)\) 表征每个样本，并为每个样本计算 \(p(b|a)\)。



后验概率分解公式：\[ p(x_{0:t}, l_{1:M} | z_{1:t}, u_{1:t}) = p(x_{0:t} | z_{1:t}, u_{1:t}) \prod_{i=1}^M p(l_i | x_{0:t}, z_{1:t}, u_{1:t}) \] 其中：





\(p(x_{0:t} | z_{1:t}, u_{1:t})\)：机器人位姿序列（路径）估计，通过粒子滤波实现。



\(\prod p(l_i | x_{0:t}, z_{1:t}, u_{1:t})\)：地图（路标）构建，在给定路径下，各路标相互独立，通过2维EKF实现。

3.2.2 机器人路径(位姿)估计





基于采样(粒子)的机器人位姿表示：每个粒子作为一条完整的机器人路径的假设。



粒子滤波重采样机制：过去的位姿信息不进行修正，因此仅需维护当前位姿。

3.2.3 粒子数据结构





采用粒子分布表示机器人路径的后验概率。



采用高斯分布表示特征（路标）的后验概率。



每个特征用一个 \(2 \times 2\) EKF表征（方差、均值）。



每个粒子仅需维护 \(M\) 个独立的EKF。

3.2.4 粒子滤波流程





运动更新：根据运动模型预测粒子位姿。



数据关联与观测更新：将观测到的特征与地图中的特征进行匹配。



基于EKF的地图更新：利用观测信息更新对应特征的EKF（均值和方差）。



基于观测的权重计算：根据卡尔曼滤波的估计方差对粒子重要性进行评估，基于权重对粒子进行重采样。

3.2.5 权重计算





目标分布：\(p(x_{1:t}^{[k]} | z_{1:t}, u_{1:t})\)



建议分布：\(p(x_t^{[k]} | x_{t-1}^{[k]}, u_t) p(x_{1:t-1}^{[k]} | z_{1:t-1}, u_{1:t-1})\)



重要性指标（权重）：\[ \omega^{[k]} = \frac{\text{target}(x^{[k]})}{\text{proposal}(x^{[k]})} = \omega^{[k]} p(z_t | x_{1:t}^{[k]}, z_{1:t-1}) \] 权重更新仅与当前观测相关。

3.2.6 数据关联





任务：确定观测的特征属于地图中的哪个特征。



匹配概率：依据观测值距离特征均值的大小和方向，由高斯分布确定匹配概率。



关联方法：





选择概率大的进行匹配。



按照概率进行随机匹配。



如果匹配概率过低，则将其视为新特征。



优势：FastSLAM利用多假设分析，可以在数据关联时忽略机器人位姿误差的影响。基于随机采样的数据关联算法简单且有效，相较于EKF这是最重要的优势。

3.2.8 FastSLAM总结





利用RBPF将SLAM后验估计问题进行降维，提升算法效率。



利用粒子采样进行机器人位姿和路径估计。



利用给定的粒子路径计算特征位置。



基于随机采样的数据关联具有更高的鲁棒性。



利用多假设分析可以在数据关联时忽略机器人位姿误差的影响。



粒子数量的选取：影响内存利用率和计算效率，粒子过少可能导致粒子枯竭（定位与建图错误）。



应用实例：GMAPPING。



4.1 Graph-based SLAM——基于优化的思想

基本思想





机器人运动过程中，位姿通过某种约束相互连接，这种约束体现了不确定性。



当机器人观测到已构建地图的区域（闭环检测），会与之前位姿状态构成额外约束。



利用优化思想，基于观测数据对机器人位姿进行修正，以使机器人观测结果最优。



图论描述：





节点：表征SLAM过程中机器人的位姿。



边：表征机器人位姿间的空间约束。



图优化SLAM：构建图，寻求最优的节点构型使得约束误差最小。

4.2 Graph-based SLAM算法构成





基于图优化的SLAM是构建图（前端）与图优化（后端）不断迭代的结果。



前端：Graph Construction，处理原始数据，构建节点和边。



后端：Graph Optimization，调整节点位置以最小化误差。



一致性地图描述有助于通过减少搜索空间来确定新的约束。



可支持在线SLAM，也可离线优化。

4.3.1 前端(图的构建)——节点





节点：





机器人位姿：\(x_i = (x, y, \theta)\)，表示机器人 \(t_i\) 时刻的位姿。



特征或路标：\(m_i = (x, y)\)，表示第 \(i\) 个路标。



图的类型：





Pose Graph：仅含有位姿节点。



Pose-feature Graph：含有位姿节点和特征节点。

4.3.2 前端(图的构建)——边





边：节点间的空间约束。





里程计测量：机器人状态 \(x_i\) 运动至 \(x_{i+1}\)，两者间的相对位姿关系的估计。



观测：





机器人在状态 \(x_i\) 和状态 \(x_j\) 下对同一环境的观测，构建虚拟测量，获得相对位姿关系。



机器人状态 \(x_i\) 观测路标 \(m_j\) 的状态。



数学描述（齐次坐标）：





机器人状态 \(X_i\) 对应齐次坐标： \[ X_i = \begin{bmatrix} \cos \omega_i & -\sin \omega_i & x_i \\ \sin \omega_i & \cos \omega_i & y_i \\ 0 & 0 & 1 \end{bmatrix} \]



里程计测量得到的边（相对变换）：\(Z_{ij} = X_i^{-1} X_j\)。



观测边（机器人观测路标）：\(\hat{z}_{ij}(x_i, m_j) = R_i^{-1} (m_j - t_i)\)。



信息矩阵：





每个边上的信息矩阵 \(\Omega_{ij}\) 描述两节点间空间约束关系的不确定性。



信息矩阵的“值越大”，节点相关性越高，优化过程中越应重视（权重越大）。

4.4.1 后端(优化算法)——优化目标函数





系统状态向量：





Pose Graph: \(\vec{x} = [\vec{x}_1, \vec{x}_2, \dots, \vec{x}_n]^T \in \mathbb{R}^{3n}\)



Pose Feature Graph: \(\vec{x} = [\vec{x}_1, \dots, \vec{x}_n, \vec{m}_1, \dots, \vec{m}_K]^T \in \mathbb{R}^{3n+2K}\)



目标：寻找最优状态 \(\vec{x}^*\) 使得总误差最小： \[ \vec{x}^* = \operatorname*{arg\,min}_{\vec{x}} \sum_{\langle i, j \rangle} e_{ij}(\vec{x})^T \Omega_{ij} e_{ij}(\vec{x}) \]

4.4.2 后端(优化算法)——误差的描述





误差函数：





Pose Graph: \(e_{ij}(x_i, x_j) = \text{ln}(Z_{ij}^{-1} X_i^{-1} X_j)\)，当 \(e_{ij}(x_i, x_j) = 0\) 时，表示边约束满足。



Pose Feature Graph: \(e_{ij}(z_i, x_j) = \hat{z}_{ij} - z_{ij} = R_j^{-1}(z_i - t_j) - z_{ij}\)，当 \(e_{ij}(z_i, x_j) = 0\) 时，表示观测与地图一致。

例4.1 Pose Graph





场景：机器人从 \(x_0\) 前进1m到 \(x_1\)，后退0.8m到 \(x_2\)，闭环检测显示回到起点（\(x_2\) 到 \(x_0\) 距离为0）。



优化目标：最小化 \(c = x_0^2 + (x_1 - x_0 - 1)^2 + (x_2 - x_1 + 0.8)^2 + (x_2 - x_0)^2\)。



结果：通过求解线性方程组得到修正后的位姿。

例4.2 Pose Feature Graph





场景：机器人 \(x_0\) 观测到前方2m处路标 \(l_0\)；前进1m到 \(x_1\)，观测到路标在前方0.8m。



优化目标：最小化里程计误差与观测误差的平方和。



结果：求解得到修正后的机器人位姿和路标位置。

4.4.3 后端(优化算法)——优化求解





非线性最小二乘问题：通常使用高斯-牛顿法求解。



高斯-牛顿法步骤：





定义误差函数 \(e_k(\tilde{x}_k + \Delta x)\)。



线性化误差函数：\(e_k(\tilde{x}_k + \Delta x) \approx e_k + J_k \Delta x\)。



计算导数并设为0，构建线性方程组：\((J_k^T \Omega_k J_k) \Delta x = -J_k^T \Omega_k e_k\)，即 \(H \Delta x = -b\)。



求解线性系统得到增量 \(\Delta x\)。



更新状态并迭代直至收敛。

4.4.4 优化求解思路





雅可比矩阵：对于边 \(x_i x_j\)，其误差函数仅与 \(x_i\) 和 \(x_j\) 相关。 \[ J_{ij} = \frac{\partial e_{ij}(x)}{\partial x} = [\dots, A_{ij}, \dots, B_{ij}, \dots] \] 其中 \(A_{ij} = \frac{\partial e_{ij}}{\partial x_i}\), \(B_{ij} = \frac{\partial e_{ij}}{\partial x_j}\)。



稀疏性：





向量 \(b\) 的更新：\(\bar{b}_i \mathrel{+}= e_{ij}^T \Omega_{ij} A_{ij}\), \(\bar{b}_j \mathrel{+}= e_{ij}^T \Omega_{ij} B_{ij}\)。



矩阵 \(H\) 的更新：仅在 \((i,i), (i,j), (j,i), (j,j)\) 块处有非零值。



\(H\) 为大型稀疏矩阵。

4.4.5 优化解的数据结构特性





稀疏矩阵优势：高斯牛顿法需要对大型矩阵 \(H\) 求逆，利用稀疏性可大幅提高效率。



求解方法：Sparse Cholesky decomposition（稀疏乔莱斯基分解）、Conjugate gradients（共轭梯度法）等。



非满秩情况处理：





增加约束：固定一个节点（通常固定 \(x_i\)），消除自由度。



Levenberg-Marquardt算法：若 \(H\) 不满秩，引入阻尼因子 \(\lambda\)，修改方程为 \((H + \lambda I) \Delta x = -b\)。

例4.3





场景：\(x_0=0, x_1=0.8\)。虚拟测量 \(z_{12}=1\)，方差0.4（信息矩阵 \(\Omega=2.5\)）。



计算误差 \(e_{12} = 0.2\)，雅可比 \(J_{12} = [1, -1]\)。



更新 \(H_{12}\) 和 \(b_{12}\)。



求解 \(\Delta x\)，更新节点状态。

4.5 Graph SLAM总结





利用图论方法表征SLAM问题：节点代表机器人状态，边代表相对位姿约束关系，具有一致性表征。



仅将实际发生关联的约束构建连接进行优化，算法效率大大提升。



并非每次观测均需要优化更新（如多分辨率地图策略）。



优化思想取代概率思想，算法容易理解，便于计算。



常用库：g2o, Karto, Carter等。

本章内容

1. 运动规划

1.1 定义与需求





定义：运动规划是一个过程，根据所给定的地图，寻找从起始状态到目标状态的运动序列。运动规划常常需要在运动受到约束的条件下找到最优解。



需求：





安全性：规避障碍物。



可达性：从起点到终点的连通域。



光滑性：能量优化，运行的平稳性，舒适性。



可执行性：





机器人在动力学约束下的运行可行性。



机器人执行单元的性能约束：速度、加速度、加加速度。

1.2 移动机器人运动规划方法





分层规划思想：





路径规划：只考虑工作空间（环境）的几何约束，不考虑机器人和执行器约束。





基于图搜索的路径规划算法。



基于采样的路径规划算法。



轨迹规划：在给定路径上，考虑机器人和执行器约束生成随时间变化的运动序列。





在线轨迹规划。



离线轨迹规划。



路径规划详解：





定义：在自由构型空间中寻求一条从初始位置到目标位置的联通路径。



构型空间 (C-Space)：机器人简化为一个可移动的点，不考虑姿态和体积。





包含自由空间和障碍物空间。



完备性：当解存在时，能够在有限时间内找到解。





算法完备：基于图搜索方法。如果在起始点和目标点间有路径解存在那么一定可以得到解，如果得不到解那么一定说明没有解存在。优势是解的捕获能力完全，缺点是算法复杂度较大。



概率完备：基于采样的方法。一般不直接在 grid 地图进行最小栅格分辨率的规划，而是采用在地图上随机撒一定密度的粒子来抽象实际地图辅助规划。速度较快，但生成的路径代价较完备的算法高，且会产生“有解求不出”的情况。一般在高维度的规划问题中广泛运用。

2. 基于图搜索的静态路径规划

2.1 图搜索的基本概念





图：一系列顶点的集合，这些顶点通过一系列边连接。



图搜索：将机器人的位姿简化成一个点，在图的空间内搜索一条从初始节点到目标节点的联通路径。涉及拓扑图的构建和基于拓扑图的节点关联关系。

2.2 图的构建





可视图：





可实现无碰撞的最短距离规划。



缺点是路径太过靠近障碍物。



维诺图：





产生的路径距离周围两个最近的障碍物的距离相等。



最大化与障碍物的距离，最为安全。



包括 \(L_1\) 距离下的维诺图路径和 \(L_2\) 距离下的维诺图路径。



精确单元分解地图。



栅格地图。



拓扑地图。



搜索树：





基于构建的图，依照起点及其对应连接关系构建搜索树，实现最优路径的选取。



将起点设为搜索树的根节点，寻求与该节点相连的所有节点作为子节点。



每个节点与一个规划路径相关联（搜索树上从根节点到该节点的连线）。



Open set (开放列表)：维护前沿（未扩展）计划的列表，通常存储为优先队列。



Closed set (关闭列表)：用于跟踪已扩展的节点。对于 Closed set 中的每个节点，已经找到了从起点到该节点的成本最低路径。

2.3 图搜索算法





深度优先搜索 (DFS)：





以深度做为优先级进行搜索，遍历每一个分支，直到找到终点。



使用栈结构。



具有完备性，但不具备最优性（不能保证最短路径，仅考虑节点连接属性，未考虑连接代价）。



无方向性，效率低下。



宽度优先搜索 (BFS / 泛洪搜索)：





以广度做为优先级进行搜索，遍历起点周围邻近的点，逐步向外扩散，直到找到终点。



使用 FIFO 队列。



具有完备性，但不具备最优性（未考虑连接代价）。



无方向性，效率低下。



Dijkstra 算法：





基于宽度优先算法，具有完备性。



计算每一个节点距离起点的总移动代价。



使用优先队列结构，每次选出代价最小的节点作为下一个遍历节点。



保证路径规划的最优性，但无法解决效率问题（地图信息利用不充分）。



A 算法*：





在 Dijkstra 算法基础上，结合目标进行搜索，是一种启发式算法（目标牵引）。



评估函数：\(f(n) = g(n) + h(n)\)





\(g(n)\)：从出发点到当前节点的路径代价。



\(h(n)\)：当前节点到目标节点的路径代价估计（启发函数）。



性质：具有完备性和可采纳性。



启发函数：





曼哈顿距离：\(|x_1 - x_2| + |y_1 - y_2|\)



欧几里得距离：\(\sqrt{(x_1 - x_2)^2 + (y_1 - y_2)^2}\)



切比雪夫距离：\(\max(|x_1 - x_2|, |y_1 - y_2|)\)



Zero：退化为 Dijkstra 算法。



算法流程：





将源节点 \(S\) 放入 OPEN 列表中并计算 \(f\) 值。



取出 OPEN 列表中 \(f\) 值最小的点 \(n\)，若点 \(n\) 为目标节点，则结束程序，完成规划。



寻找周围可达节点，并将 \(n\) 设为其父节点，对于 \(n\) 的每一个子节点 \(t\)：





如果 \(t\) 从未被扩展过，则计算其 \(f\) 值并将其加入 OPEN 表中。



如果 \(t\) 在 OPEN 表中，则重新计算其 \(f\) 值，如果比原来的值小，则选取小的 \(f\) 值。



如果 \(t\) 在 CLOSE 表中，则跳过 \(t\)。



从 Open List 中移除 \(n\)，放入 Close 列表，返回 Step 2。



特点：





由于启发函数的存在，算法效率明显高于 Dijkstra 算法。



最佳路线可能有多条。



启发式函数的估算方法优劣是影响算法效率的重要因素。



不保证得到的路线是平滑的。



A* 算法距离最短，非运行时间最短（需考虑转向成本，可增加额外的 G 值）。



搜索效率提升方法：优化 Open List 数据结构、使用多分辨率地图、加大启发式函数的权重。



权重 A 算法*：





通过加大启发函数的权重（膨胀系数 \(\epsilon\)），提升算法效率。



膨胀系数 \(\epsilon \ge 1\)。



路径评价函数：\(f(n) = g(n) + \epsilon \cdot h(n)\)。



权重增加会限制扩展节点的方向，提高速度，但不满足可采纳性，只能得到局部最优解。



ARA 算法*：





结合了任意时间法 和权重 A*，兼顾效率与性能。



任意时间法：在很短的时间内先得出一个次优的解法，然后再对这个解法进行不断的优化。



流程：





膨胀系数 \(\epsilon\) 先取一个较大值（如 2.5），提升算法速度，快速得到一条路径。



不断降低 \(\epsilon\)（直至为 1），对路径进行优化。



引入 INCONS 表：防止已经进入 CLOSED 表的节点不再进入 OPEN 表中进行二次扩展，减少重复计算。



特点：





相比于 A* 算法，二者得出的最优路径是相同的。



ARA* 算法得到最优路径和 A* 算法的时间近乎没有损失。



能更好地适用于对时间有苛刻限制的情况。



与 A* 算法一样，仅限于静态环境下使用。

1. 机器人地图

1.1 机器人地图的基本概念





地图：环境信息的一种表达方法，是移动机器人定位导航的基础。



定位：通过环境感知信息和地图信息的匹配，确定移动机器人在环境中的位置。



导航规划：根据地图中所记录的连通域信息和障碍物位置，规划机器人从当前点到目标点的可行路径。

1.2 机器人地图的表示方法

地图表示法需具备以下功能：





支撑机器人完成特定任务（定位、导航、规划）。



容易加入新信息以更新地图。



便于计算机进行存储和处理。

常用地图表示法：





点云地图



栅格地图



特征地图



拓扑地图



1.3 点云地图

概念

点云地图是直接由占用空间的点集合表示的地图。





数学描述：\[ P = \{p_1, p_2, \dots, p_n\} \] 其中 \(p_i = (x_i, y_i)\) 或 \(p_i = (x_i, y_i, z_i)\)。

构建方法

通过激光雷达等传感器获取点云数据，并将不同时刻、不同位姿下的点云数据转换到统一的世界坐标系 \(\{W\}\) 中进行拼接。

优缺点





优点：





可以完全表示环境三维信息。



所构建地图不需要预先定义尺寸。



缺点：





存储要求高（如16线3D激光雷达点云数据有30万点/秒）。



存在检测盲区和空洞。



不能单凭点的占用来判断空间的占用、联通状态，需要处理后才能得到导航所需地图（如地面提取）。



不具有通用性，不同机器人或激光雷达因高度、角度不同，需要重新构建地图。



1.4 栅格地图

概念

将连续空间分解为一系列离散栅格，每个栅格有一个表征该栅格占用属性的值。





平面栅格属性的值：





定位：0-1的值，用以描述该栅格被占用的概率。



导航：0或1，描述是否可以通过。

构建方法





空间栅格化：栅格的大小可以用允许误差的大小确定。



空间栅格的占用情况：





概率架构下的表示为以激光测量数据为条件的栅格占用概率 \(p(m_i | s_1, s_2, \dots, s_n)\)，其中 \(s_1, \dots, s_n\) 为激光数据，\(m_i\) 为第 \(i\) 个栅格。



采用几率对数形式的二元贝叶斯滤波法求解。



几率（Odds）：栅格被占的概率除以空闲概率。\[ l = \frac{p(m_i|s_1, s_2, \dots, s_n)}{p(\bar{m}_i|s_1, s_2, \dots, s_n)} = \frac{p(m_i|s_1, s_2, \dots, s_n)}{1 - p(m_i|s_1, s_2, \dots, s_n)} \]



几率对数求解： 利用贝叶斯公式和激光测量的独立性，可得递推公式：\[ l_{i,n} = \log \frac{p(m_i|s_n)}{p(\bar{m}_i|s_n)} + l_0 + l_{i,n-1} \] 若栅格 \(i\) 被占用情况未知，\(p(m_i) = 0.5 \Rightarrow l_0 = 0\)。

激光的逆传感器模型 \(p(m_i|s_n)\)

根据障碍物距离测量数据 \(\rho_i, \theta_i\)，估计栅格单元的被占用概率：

\[ p(m_i|s_n) = 1 - E_r E_\omega \]

其中：

\[ E_r = 1 - \exp\left(-\frac{(r_i - \rho_i)^2}{2\sigma_r^2}\right), \quad E_\omega = 1 - \exp\left(-\frac{(\epsilon_i - \vartheta)^2}{2\sigma_\omega^2}\right) \]

栅格地图的扩展





2.5维占用栅格地图（如NASA火星车）：





高度图：在每个栅格上增加一个属性，即该栅格上障碍物最高部分的高度估计信息。



缺点：会存在虚拟障碍物问题。



扩展高度图表示法：





对栅格进行识别，确定栅格是立体结构还是包含空隙。



检查单元所对应的所有数据点的高度方差。



每个单元仅能表示1层信息。



3维占用栅格地图（体素地图，Voxel Map）：





将空间分解为大小相同的正方体。



每一个正方体描述所在位置是否被占用。



原理简单，扩展性强，但占用大量存储空间。



多分辨率地图：





针对栅格地图空间占用率高、计算复杂度高、存储存在稀疏特性的问题。



采用八叉树表示，存储效率高。

优缺点





优点：





可以详细地描述环境信息。



易于机器人进行定位和路径规划。



缺点：





存储要求高：随着栅格数量的增加和环境的扩大，地图所需内存和维护时间也迅速增长。



1.5 特征地图（语义地图）





包括连续线性地图、连续多边形地图。



空间占用效率高，定位精度高。



1.6 拓扑地图





把环境表示为带节点和相关连接线的拓扑结构图。





节点：表示环境中的重要位置点。



边：表示节点间的连接关系。



常见的地铁公交线路图均为拓扑地图。



非常方便进行导航和路径规划。



可由点云地图、栅格地图、特征地图抽象而来。



由于信息抽象，难于用于机器人精确可靠的定位。



2. 同步定位建图算法 (SLAM)

2.1 基本概念





定位：





根据环境地图和机器人的运动序列、观测序列，来确定机器人在地图中的位置和姿态。



误差来源：全局定位的初始误差、局部定位中的观测噪声。



前提：地图是已知的。



建图：





根据观测序列和机器人的位置和姿态，来确定环境信息。



误差来源：观测噪声。



前提：机器人的位置和姿态是已知的。



SLAM (Simultaneous Localization and Mapping)：





根据机器人的运动序列、观测序列，同时估计机器人的位置和姿态以及环境地图。



SLAM问题是“先有鸡还是先有蛋”的问题：建图需要机器人位姿信息，机器人定位需要地图信息。

2.2 发展历程与关键问题





历史：





1986年ICRA会议提出——概率方法求解（当时认为地图的构建和机器人状态误差不可收敛）。



1996年证明可以收敛，并给出收敛的条件（2001年TRO的论文，SLAM的奠基性论文）。



收敛条件：





路标测量误差具有一致性。



每一次测量时两路标间的相对关系较为准确，随着观测增加，路标间的关联强度越高，地图估计越准确。



数据关联：





是SLAM实现收敛的关键，错误匹配会使得SLAM算法发散。



闭环检测：





当机器人在SLAM过程中回到以前到过的地方，也要和之前的观测建立正确的数据关联。



这个数据关联称之为闭环检测，可以有效降低估计的不确定性。

3. 基于滤波方法的SLAM算法

3.1 EKF-SLAM

3.1.1 概述





第一个SLAM算法（1986年）。



面向特征地图，特别是路标特征地图。



采用最大似然进行数据关联。



假设特征彼此清晰可分。



机器人运动和观测噪声满足高斯分布。



以机器人初始位姿为地图坐标系原点。



与EKF机器人定位问题类似，但维度大大增加。

3.1.2 状态向量与协方差矩阵





待估计状态 \(x_t \in \mathbb{R}^{3+2n}\)：\[ x_t = \begin{bmatrix} X_R \\ M_1 \\ M_2 \\ \vdots \\ M_n \end{bmatrix} \] 其中 \(X_R\) 为机器人位姿，\(M_i\) 为第 \(i\) 个路标的位置。



协方差矩阵 \(\Sigma_t\)： 包含机器人位姿方差、路标方差以及它们之间的互相关方差。\[ \Sigma_t = \begin{bmatrix} \Sigma_{X_R} & \Sigma_{X_R m_1} & \dots & \Sigma_{X_R m_n} \\ \Sigma_{m_1 X_R} & \Sigma_{m_1} & \dots & \Sigma_{m_1 m_n} \\ \vdots & \vdots & \ddots & \vdots \\ \Sigma_{m_n X_R} & \Sigma_{m_n m_1} & \dots & \Sigma_{m_n} \end{bmatrix} \]



初始状态：\[ x_0 = 0_{(3+2n) \times 1}, \quad \Sigma_{X_R} = 0_{3 \times 3}, \quad \Sigma_{X_R m_i} = 0_{3 \times 2}, \quad \Sigma_{m_i} = \begin{bmatrix} \infty & 0 \\ 0 & \infty \end{bmatrix} \]

3.1.3 算法流程





State Prediction (状态预测)：基于运动模型进行状态估计。\[ \bar{x}_t = f(x_{t-1}, u_{t-1}) \] \[ \bar{\Sigma}_t = \nabla f \cdot \Sigma_{t-1} \cdot \nabla f^T + F_x R_t F_x^T \] 其中 \(F_x\) 是运动模型关于状态的雅可比矩阵，对于路标部分为单位矩阵。



Measurement Prediction (观测预测)：基于观测模型进行观测预测。\[ \hat{Z}_t = h(\bar{X}_R) \]



Observation (观测)：获得本次观测 \(Z_t\)。



Data Association (数据关联)：建立预估观测与本次观测的数据关联。



Update (更新)：利用Kalman增益进行状态更新。



Integration of new landmark (加入新特征)：在地图中加入新的路标。

3.1.4 运动模型与观测模型





里程计模型：\[ \begin{bmatrix} x' \\ y' \\ \theta' \end{bmatrix} = \begin{bmatrix} x \\ y \\ \theta \end{bmatrix} + \begin{bmatrix} \frac{v_t}{\omega_t} \sin(\theta + \omega_t \Delta t) - \frac{v_t}{\omega_t} \sin \theta \\ \frac{v_t}{\omega_t} \cos \theta - \frac{v_t}{\omega_t} \cos(\theta + \omega_t \Delta t) \\ \omega_t \Delta t \end{bmatrix} \]



观测模型： 对于激光测量数据 \(z_i^t = [r_i^t, \omega_i^t]^T\)（机器人坐标系），需投影到世界坐标系。 观测雅可比矩阵 \(H_t\) 描述了观测值对状态（机器人位姿和路标）的偏导数。

3.1.5 加入新特征

当发现新路标 \(m_{n+1}\) 时：





从机器人坐标转换到世界坐标：\(m_{n+1} = f(X_R, z_{n+1})\)。



计算新路标的协方差及与机器人、旧路标的互协方差：\[ \Sigma_{m_{n+1}} = \nabla f_R \cdot \Sigma_{X_R} \cdot \nabla f_R^T + \nabla f_Z \cdot \Sigma_{Z_{n+1}} \cdot \nabla f_Z^T \] \[ \Sigma_{m_{n+1} m_i} = \nabla f_R \cdot \Sigma_{X_R m_i} \]

3.1.6 实验效果





蓝色：真实轨迹。



红色：EKF-SLAM估计轨迹。



绿色：里程计估计轨迹。

3.1.7 EKF-SLAM存在的问题





所有路标之间为全连接，计算复杂度高，无法在大场景地图下使用。



要求高斯分布，因此只能处理单峰假设。



一旦数据关联错误，将导致发散。



仅适用于人工路标情况。



只能用点云地图或特征地图，无法使用栅格地图。

3.1.8 EKF-SLAM回环检测





识别已建图区域。



数据关联具有高度模糊性（可能的环境对称性）。



闭环后不确定性会坍缩（无论闭环是否正确）。

3.1.9 EKF-SLAM算法总结





使用多变量高斯函数来表达机器人的位姿和路标估计。



高斯协方差矩阵包含高度互相关信息。



EKF致命缺点：





计算复杂度：协方差矩阵大小为 \((2N+3) \times (2N+3)\)。只要观测到一个路标，整个协方差矩阵被更新。面对大量路标的复杂自然环境，难以满足实时性要求。



数据关联：单假设数据关联。将观测值与最可能产生它的路标相关联。即使一小部分的错误关联也会导致算法发散。改善方法（如考虑多个观测值）会增加计算损耗，且不能根本解决潜在问题。

3.2 FastSLAM

简介





FastSLAM 由 Montemerlo 等人于 2003 年首次提出。



FastSLAM 是粒子滤波器与 EKF 的集成。

核心思想





机器人路径估计：使用改进的粒子滤波器估计机器人路径的后验分布。机器人的位姿通过粒子分布来表示。每个粒子代表一条可能的运动路径，利用观测信息计算每个粒子的权重，以评价每条路径的好坏。



路标估计：路标使用 EKF 来估计。即每个粒子拥有 \(N\) 个 EKF（2维），用于在路径估计条件下对 \(N\) 个路标位置进行估计。



条件独立性：在机器人路径已知的情况下，路标位置的估计相对独立。

3.2.1 Rao-Blackwellization Particle Filter (RBPF)

粒子维度问题





AMCL 算法中，粒子的维度为 3 维：\([x, y, \theta]\)。



FastSLAM 粒子的维度为 \(3t + 2N\) 维：\[ x = (x_{1:t}, l_{1,x}, l_{1,y}, l_{2,x}, l_{2,y}, \dots, l_{N,x}, l_{N,y})^T \]



粒子滤波器在低维空间中有效，因为需要用样本覆盖状态空间的可能体积。如何降维是关键问题。

粒子降维的核心思想





已知 \(x_{1:t}, l_{1,x}, l_{1,y}, l_{2,x}, l_{2,y}, \dots, l_{N,x}, l_{N,y}\)。



如果利用粒子对机器人路径进行建模，对于每个粒子而言，就是对机器人路径的一个假设。因此，对于每一个粒子，能独立地计算一套路标的地图。

Rao-Blackwell 定理





以一个任意的原始估计为起点，寻找最小方差无偏估计量 (MVUE)。



利用变量间依赖关系进行的因式分解。



如果可以得到 \(p(b|a)\) 的封闭解，可以用 \(p(a)\) 表征每个样本，并为每个样本计算 \(p(b|a)\)。



概率分解公式：\[ p(x_{0:t}, l_{1:M} | z_{1:t}, u_{1:t}) = p(x_{0:t} | z_{1:t}, u_{1:t}) p(l_{1:M} | x_{0:t}, z_{1:t}, u_{1:t}) \] \[ = p(x_{0:t} | z_{1:t}, u_{1:t}) \prod_{i=1}^{M} p(l_i | x_{0:t}, z_{1:t}, u_{1:t}) \]



已知条件：在给定机器人路径的情况下，路标变量都是断开的（即独立的）。

3.2.2 机器人路径(位姿)估计





基于采样(粒子)的机器人位姿表示：





每个粒子作为一条完整的机器人路径的假设。



初始位姿通常取 \((0, 0, 0)\)。



\(t=1\) 时为机器人位姿假设，\(t=2\) 时为机器人位姿假设，以此类推。



粒子滤波重采样机制：





过去的位姿信息不进行修正，因此，仅需维护当前位姿。

3.2.3 粒子数据结构





采用粒子分布表示机器人路径的后验概率。



采用高斯分布表示特征的后验概率。



每个特征（路标）用一个 \(2 \times 2\) EKF 表征（方差，均值）。



每个粒子仅需维护 \(M\) 个独立的 EKF。

3.2.4 粒子滤波流程





运动更新：





根据运动模型预测粒子的新位姿。



数据关联与观测更新：





确定观测到的特征对应地图中的哪个路标。



基于 EKF 的地图更新：





利用观测信息更新对应路标的 EKF（均值和方差）。



如果是新特征，则初始化一个新的 EKF。



基于观测的权重计算：





根据卡尔曼滤波的估计方差对粒子重要性进行评估。



基于权重对粒子进行重采样。

3.2.5 权重计算





目标分布：\[ p(x^{[k]}_{1:t} | z_{1:t}, u_{1:t}) = \frac{p(z_t | x^{[k]}_{1:t}, z_{1:t-1}) p(x^{[k]}_t | x^{[k]}_{t-1}, u_t) p(x^{[k]}_{1:t-1} | z_{1:t-1}, u_{1:t-1})}{p(z_t | z_{1:t-1}, u_{1:t})} \]



建议分布：\[ p(x^{[k]}_{1:t} | z_{1:t-1}, u_{1:t}) = p(x^{[k]}_t | x^{[k]}_{t-1}, u_t) p(x^{[k]}_{1:t-1} | z_{1:t-1}, u_{1:t-1}) \]



重要性指标：\[ \omega^{[k]} = \frac{\text{target}(x^{[k]})}{\text{proposal}(x^{[k]})} \] 根据贝叶斯公式推导，重要度指标仅与当前观测相关：\[ \omega^{[k]} = \omega^{[k]} p(z_t | x^{[k]}_{1:t}, z_{1:t-1}) \]

3.2.6 数据关联





问题：观测的特征属于地图中的哪个特征。存在多种匹配的可能。



基础：数据匹配是以基于机器人位姿为基础的。机器人位姿估计误差直接影响数据匹配结果。每个粒子代表一个机器人位姿估计。



匹配概率：





地图中特征的位置和方差已知。



依据观测值距离特征均值的大小和方向，由高斯分布可以确定其匹配概率。



数据关联方法：





选择概率大的进行匹配。



按照概率进行随机匹配。



如果匹配概率过低，产生一个新特征。



优势：FastSLAM 利用多假设分析可以在数据关联时忽略机器人位姿误差的影响。基于随机采样的数据关联算法简单且有效——相较于 EKF 最重要的优势。

利用 RBPF 将 SLAM 后验估计问题进行降维，提升算法的效率。

4.1 Graph-based SLAM——基于优化的思想





基本概念：





机器人运动过程中，机器人位姿通过某种约束相互连接。这种约束体现了不确定性。



当机器人观测到已构建地图的区域，会与之前机器人位姿状态构成额外约束。



利用优化思想，基于观测数据对机器人位姿进行修正，以使机器人观测结果最优。



图论描述：





使用图中的节点表征 SLAM 过程中机器人的位姿。



两个节点间的边表征机器人位姿间的空间约束。



图优化 SLAM：构建图，寻求最优的节点构型使得约束误差最小。





图中的每一个节点均代表一个机器人位姿。



图中的两个节点间的边代表了节点间的空间约束。



基于构建的图和图中节点的约束关系，可以以此修正节点（机器人的位姿）以最大程度上满足空间约束（即边的约束）。



基于修正的节点位姿（机器人的位姿）修正地图。

4.2 Graph-based SLAM 算法构成





基于图优化的 SLAM 就是构建图（前端）与图优化（后端）不断迭代的结果。



一致性地图描述有助于通过减少搜索空间来确定新的约束。



可在线 SLAM，也可离线优化。



流程：





Graph Construction (Front-End)：原始数据 -> 图（节点和边）。



Graph Optimization (Back-End)：图 -> 优化后的节点位置。

4.3.1 前端(图的构建)——节点





节点：





机器人位姿：\(x_i = (x, y, \theta)\)，其中 \(x_i\) 为机器人 \(t_i\) 时刻的位姿。



特征或路标：\(m_i = (x, y)\)，其中 \(m_i\) 为第 \(i\) 个路标。



类型：





仅含有位姿节点的图：Pose Graph。



含有特征的图：Pose-feature Graph。

4.3.2 前端(图的构建)——边





边：节点间的空间约束。





里程计测量：机器人状态 \(x_i\) 运行至 \(x_{i+1}\)，两者间的相对位姿关系的估计。



观测：





机器人在状态 \(x_i\) 和状态 \(x_{i+1}\) 下对同一环境下的观测。



构建虚拟测量，获得从状态 \(x_i\) “观测”状态 \(x_{i+1}\)，获得相对位姿关系。



机器人状态 \(x_i\) 观测路标 \(m_j\) 的状态。



边的数学描述（齐次坐标）：





边描述的是相对位姿关系。



里程计测量：





机器人状态 \(X_i\) 对应齐次坐标描述为：\[ X_i = \begin{bmatrix} \cos \omega_i & -\sin \omega_i & x_i \\ \sin \omega_i & \cos \omega_i & y_i \\ 0 & 0 & 1 \end{bmatrix} \]



里程计测量得到的边为 \(Z_{ij}\)。



观测：





机器人在状态 \(X_i\) 和状态 \(X_j\) 下对同一环境下的观测。



构建虚拟测量，获得从状态 \(X_i\) “观测”状态 \(X_j\)，获得相对位姿关系为 \(Z_{ij} = X_i^{-1} X_j\)。



机器人状态 \(X_i\) 观测路标 \(m_j\) 的状态：\(\hat{z}_{ij}(x_i, m_j) = R_i^{-1} (m_j - t_i)\)。



边的信息矩阵：





观测受传感器测量噪声影响。



每个边上的信息矩阵 \(\Omega_{ij}\) 描述两节点间空间约束关系的不确定性。



信息矩阵的“值越大”，节点相关性越高，优化过程中越应重视。



信息矩阵描述了每个边的约束在优化过程中的权重。



问题：基于观测的边的信息矩阵与基于里程计测量的信息矩阵形式上的差别；非完整约束下信息矩阵的形态（如很长的走廊）。

4.4.1 后端(优化算法)——优化目标函数





系统状态向量：





for Pose Graph: \(\vec{x} = (\vec{x}_1, \vec{x}_2, \dots, \vec{x}_n) \in \mathbb{R}^{3n}\)



for Pose Feature Graph: \(\vec{x} = (\vec{x}_1, \vec{x}_2, \dots, \vec{x}_n, \vec{m}_1, \vec{m}_2, \dots, \vec{m}_K) \in \mathbb{R}^{3n+2K}\)



目标：\[ \vec{x}^* = \arg \min_{\vec{x}} \sum_{ij} \vec{e}_{ij}^T \Omega_{ij} \vec{e}_{ij} \]

4.4.2 后端(优化算法)——误差的描述





误差函数 \(e_{ij}(\vec{x}_i, \vec{x}_j)\) (For Pose Graph)：





当 \(e_{ij}(\vec{x}_i, \vec{x}_j) = 0\) 时，表示节点间的关系满足边约束。



公式：\(e_{ij}(\vec{x}_i, \vec{x}_j) = t2v(Z_{ij}^{-1} (X_i^{-1} X_j))\)。



误差函数 \(e_{ij}(z_i, \vec{x}_j)\) (For Pose Feature Graph)：





当 \(e_{ij}(z_i, \vec{x}_j) = 0\) 时，表示节点间的关系满足边约束。



公式：\(e_{ij}(z_i, \vec{x}_j) = \hat{z}_{ij} - z_{ij} = R_j^{-1} (z_i - t_j) - z_{ij}\)。

例 4.1 Pose Graph假设一个机器人初始起点在 0 处 \(x_0\)，然后机器人向前移动，通过编码器测得它向前移动了 1m，到达第二个地点 \(x_1\)。接着，又向后返回到 \(x_2\)，编码器测得它向后移动了 0.8 米。但是，通过闭环检测，发现它回到了原始起点。请问，机器人位姿的最优状态。





里程计预估优化问题：





节点：\(x_0, x_1, x_2\)。



边：\((x_0, x_1) \to 1m, (x_1, x_2) \to -0.8m, (x_2, x_0) \to 0m\)。固定 \(x_0 \to 0m\)。



定义误差函数：\(f_1 = x_0\) \(f_2 = x_1 - x_0 - 1\) \(f_3 = x_2 - x_1 - (-0.8)\) \(f_4 = x_2 - x_0\)



构建优化目标函数：\(c = \sum_{i=1}^4 f_i^2 = x_0^2 + (x_1 - x_0 - 1)^2 + (x_2 - x_1 + 0.8)^2 + (x_2 - x_0)^2\)



目标函数对各个变量求偏导，列出方程：\[ \frac{\partial c}{\partial x_0} = 2x_0 - 2(x_1 - x_0 - 1) - 2(x_2 - x_0) = 0 \] \[ \frac{\partial c}{\partial x_1} = 2(x_1 - x_0 - 1) - 2(x_2 - x_1 + 0.8) = 0 \] \[ \frac{\partial c}{\partial x_2} = 2(x_2 - x_1 + 0.8) + 2(x_2 - x_0) = 0 \]



整理得线性方程组：\[ \begin{bmatrix} 3 & -1 & -1 \\ -1 & 2 & -1 \\ -1 & -1 & 2 \end{bmatrix} \begin{bmatrix} x_0 \\ x_1 \\ x_2 \end{bmatrix} = \begin{bmatrix} -1.0 \\ 1.8 \\ -0.8 \end{bmatrix} \]



求解得：\[ \begin{bmatrix} x_0 \\ x_1 \\ x_2 \end{bmatrix} = \begin{bmatrix} 0 \\ 0.93 \\ 0.07 \end{bmatrix} \]

例 4.2 Pose Feature Graph假设一个机器人初始起点在 0 处，并观测到其正前方 2m 处有一个路标。然后机器人向前移动，通过编码器测得它向前移动了 1m，这时观测到路标在其前方 0.8m。请问，机器人位姿和路标位姿的最优状态。





节点：\(x_0, x_1, l_0\)。



边：\((x_0, l_0) \to 2m, (x_0, x_1) \to 1m, (x_1, l_0) \to 0.8m\)。固定 \(x_0 \to 0m\)。



定义误差函数：\(f_1 = l_0 - x_0 - 2\) \(f_2 = x_1 - x_0 - 1\) \(f_3 = l_0 - x_1 - 0.8\) \(f_4 = x_0\)



构建优化目标函数：\(c = \sum_{i=1}^4 f_i^2 = (l_0 - x_0 - 2)^2 + (x_1 - x_0 - 1)^2 + (l_0 - x_1 - 0.8)^2 + x_0^2\)



目标函数对各个变量求偏导，列出方程：\[ \frac{\partial c}{\partial x_0} = -2(l_0 - x_0 - 2) - 2(x_1 - x_0 - 1) + 2x_0 = 0 \] \[ \frac{\partial c}{\partial x_1} = 2(x_1 - x_0 - 1) - 2(l_0 - x_1 - 0.8) = 0 \] \[ \frac{\partial c}{\partial l_0} = 2(l_0 - x_0 - 2) + 2(l_0 - x_1 - 0.8) = 0 \]



整理得线性方程组：\[ \begin{bmatrix} 3 & -1 & -1 \\ -1 & 2 & -1 \\ -1 & -1 & 2 \end{bmatrix} \begin{bmatrix} x_0 \\ x_1 \\ l_0 \end{bmatrix} = \begin{bmatrix} -3.0 \\ 0.2 \\ 2.8 \end{bmatrix} \]



求解得：\[ \begin{bmatrix} x_0 \\ x_1 \\ l_0 \end{bmatrix} = \begin{bmatrix} 0 \\ 1.07 \\ 1.93 \end{bmatrix} \]

4.4.3 后端(优化算法)——优化求解





目标函数：\(F(\vec{x}) = \sum_{k} \vec{e}_k(\vec{x})^T \Omega_k \vec{e}_k(\vec{x})\)。



非线性最小二乘：





高斯-牛顿法步骤：





Define the error function.



Linearize the error function.



Compute its derivative.



Set the derivative to zero.



Solve the linear system.



Iterate this procedure until convergence.



推导： 在当前估计 \(\tilde{x}_k\) 处进行泰勒展开：\[ \vec{e}_k(\tilde{x}_k + \Delta \vec{x}) \approx \vec{e}_k(\tilde{x}_k) + J_k \Delta \vec{x} \] 代入目标函数：\[ F(\tilde{x}_k + \Delta \vec{x}) \approx \sum (\vec{e}_k + J_k \Delta \vec{x})^T \Omega_k (\vec{e}_k + J_k \Delta \vec{x}) \] \[ = \sum (\vec{e}_k^T \Omega_k \vec{e}_k + 2\vec{e}_k^T \Omega_k J_k \Delta \vec{x} + \Delta \vec{x}^T J_k^T \Omega_k J_k \Delta \vec{x}) \] \[ = C + 2\vec{b}^T \Delta \vec{x} + \Delta \vec{x}^T H \Delta \vec{x} \] 其中：\[ \vec{b} = \sum J_k^T \Omega_k \vec{e}_k, \quad H = \sum J_k^T \Omega_k J_k \] 对 \(\Delta \vec{x}\) 求导并令其为 0：\[ \frac{\partial F}{\partial \Delta \vec{x}} = 2\vec{b} + 2H \Delta \vec{x} = 0 \] \[ \Delta \vec{x} = -H^{-1} \vec{b} = -(\sum J_k^T \Omega_k J_k)^{-1} (\sum J_k^T \Omega_k \vec{e}_k) \]

4.4.4 优化求解思路





目标函数：\(\vec{x}^* = \arg \min_{\vec{x}} \sum_{ij} \vec{e}_{ij}^T \Omega_{ij} \vec{e}_{ij}\)。



对于边 \(\vec{x}_i \vec{x}_j\) 其误差函数为：





Pose Graph: \(e_{ij}(\vec{x}_i, \vec{x}_j) = t2v(Z_{ij}^{-1} (\vec{x}_i^{-1} \vec{x}_j))\)。



Pose Feature Graph: \(e_{ij}(z_i, \vec{x}_j) = \hat{z}_{ij} - z_{ij}\)。



雅可比阵求取：





对于边 \(\vec{x}_i \vec{x}_j\) 的误差函数仅与 \(\vec{x}_i\) 和 \(\vec{x}_j\) 相关。



\(J_{ij} = \frac{\partial \vec{e}_{ij}(\vec{x})}{\partial \vec{x}}\)。



形式为：\[ J_{ij} = \begin{bmatrix} 0 & \dots & A_{ij} & \dots & B_{ij} & \dots & 0 \end{bmatrix} \] 其中 \(A_{ij} = \frac{\partial \vec{e}_{ij}}{\partial \vec{x}_i}\), \(B_{ij} = \frac{\partial \vec{e}_{ij}}{\partial \vec{x}_j}\)。



目标函数求导等于 0：\[ \vec{b} = \sum \vec{b}_{ij} = \sum \vec{e}_{ij}^T \Omega_{ij} J_{ij} \] \[ H = \sum H_{ij} = \sum J_{ij}^T \Omega_{ij} J_{ij} \] 矩阵 \(H\) 和向量 \(\vec{b}\) 具有稀疏性。

4.4.5 优化解的数据结构特性





稀疏性：





对于边 \(\vec{x}_i \vec{x}_j\) 的约束，仅能影响：





\(\vec{b}_{ij}\) 的第 \(i\) 个和第 \(j\) 个块。



\(H_{ij}\) 的 \((i, i), (i, j), (j, i), (j, j)\) 处的数据块。



\(H_{ij}\) 矩阵为稀疏矩阵。



具体结构：\[ \vec{b}_{ij} = \vec{e}_{ij}^T \Omega_{ij} J_{ij} = \begin{bmatrix} 0 & \dots & \vec{e}_{ij}^T \Omega_{ij} A_{ij} & \dots & \vec{e}_{ij}^T \Omega_{ij} B_{ij} & \dots & 0 \end{bmatrix}^T \] \[ H_{ij} = J_{ij}^T \Omega_{ij} J_{ij} = \begin{bmatrix} \dots & \dots & \dots & \dots & \dots \\ \dots & A_{ij}^T \Omega_{ij} A_{ij} & \dots & A_{ij}^T \Omega_{ij} B_{ij} & \dots \\ \dots & \dots & \dots & \dots & \dots \\ \dots & B_{ij}^T \Omega_{ij} A_{ij} & \dots & B_{ij}^T \Omega_{ij} B_{ij} & \dots \\ \dots & \dots & \dots & \dots & \dots \end{bmatrix} \]



求解：





高斯牛顿法需要对大型矩阵 \(H_k\) 求逆，由于 \(H_k\) 为稀疏矩阵，可利用稀疏矩阵求解算法：





Sparse Cholesky decomposition。



Conjugate gradients (共轭梯度法)。



… many others。

4.4.5 后端优化流程

对于每一个边 \(\vec{x}_i \vec{x}_j\) 的约束：





计算误差：\(e_{ij}(\vec{x}_i, \vec{x}_j)\)。



计算其对应的雅可比数据块：\(A_{ij} = \frac{\partial e_{ij}}{\partial \vec{x}_i}, B_{ij} = \frac{\partial e_{ij}}{\partial \vec{x}_j}\)。



更新对应的系数向量 \(\vec{b}_{ij}\) 的数据块：\[ \vec{b}_i \leftarrow \vec{b}_i + \vec{e}_{ij}^T \Omega_{ij} A_{ij} \] \[ \vec{b}_j \leftarrow \vec{b}_j + \vec{e}_{ij}^T \Omega_{ij} B_{ij} \]



更新对应的系数矩阵 \(H_{ij}\) 的数据块：\[ H_{ii} \leftarrow H_{ii} + A_{ij}^T \Omega_{ij} A_{ij} \] \[ H_{ij} \leftarrow H_{ij} + A_{ij}^T \Omega_{ij} B_{ij} \] \[ H_{ji} \leftarrow H_{ji} + B_{ij}^T \Omega_{ij} A_{ij} \] \[ H_{jj} \leftarrow H_{jj} + B_{ij}^T \Omega_{ij} B_{ij} \]



求解稀疏矩阵的逆，更新优化系统节点：\[ \Delta \vec{x} = -H^{-1} \vec{b} \] \[ \vec{x}_{k+1} = \vec{x}_k + \Delta \vec{x} \]

例 4.3假设一个机器人初始起点在 0 处 (\(x_0\))，然后机器人向前移动，通过编码器测得它向前移动了 0.8m (\(x_1\))，此时与机器人初始状态时观测到了相同环境信息，根据机器人观测的周围环境信息，可得从机器人状态 \(x_0\) 处观测机器人状态 \(x_1\) 的虚拟测量为 1，该观测的方差为 0.4。请问，机器人位姿的最优状态。





节点：\(x_0, x_1\)。



边：\(x_0 \to x_1\)，虚拟测量 \(z_{01} = 1\)，信息矩阵 \(\Omega_{01} = 1 / 0.4 = 2.5\)。



初始状态：\(x_0 = 0, x_1 = 0.8\)。



计算误差：\(e_{01} = z_{01} - (x_1 - x_0) = 1 - 0.8 = 0.2\)。



计算雅可比：\(J_{01} = \begin{bmatrix} \frac{\partial e}{\partial x_0} & \frac{\partial e}{\partial x_1} \end{bmatrix} = \begin{bmatrix} 1 & -1 \end{bmatrix}\)。



更新对应的系数向量 \(\vec{b}_{01}\)：\(\vec{b}_{01} = e_{01}^T \Omega_{01} J_{01} = 0.2 \times 2.5 \times \begin{bmatrix} 1 & -1 \end{bmatrix} = \begin{bmatrix} 0.5 & -0.5 \end{bmatrix}^T\)。



更新对应的系数矩阵 \(H_{01}\)：\(H_{01} = J_{01}^T \Omega_{01} J_{01} = \begin{bmatrix} 1 \\ -1 \end{bmatrix} 2.5 \begin{bmatrix} 1 & -1 \end{bmatrix} = \begin{bmatrix} 2.5 & -2.5 \\ -2.5 & 2.5 \end{bmatrix}\)。



更新节点 x 状态：\(\Delta \vec{x} = -H_{01}^{-1} \vec{b}_{01}\)。 由于 \(\det(H_{01}) = 0\)，矩阵不满秩，无法直接求逆。

4.4.5 系数矩阵 \(H_k\) 非满秩情况下的处理方法





增加约束：





固定一个节点：一般对于边 \(\vec{x}_i \vec{x}_j\)，固定节点 \(\vec{x}_i\)。边 \(\vec{x}_i \vec{x}_j\) 描述的是 \(\vec{x}_i\) 和 \(\vec{x}_j\) 相对位姿关系。



Simplified Levenberg Marquardt：





若 \(H_k\) 不满秩，使用阻尼因子 \(\lambda\)：\[ (H_k + \lambda I) \Delta \vec{x} = -\vec{b}_k \]



对于例 4.3，加入 \(\lambda I\)（假设 \(\lambda=1\)）：\[ H_{LM} = \begin{bmatrix} 2.5 & -2.5 \\ -2.5 & 2.5 \end{bmatrix} + \begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix} = \begin{bmatrix} 3.5 & -2.5 \\ -2.5 & 3.5 \end{bmatrix} \] \[ \Delta \vec{x} = -H_{LM}^{-1} \vec{b}_{01} = -\begin{bmatrix} 3.5 & -2.5 \\ -2.5 & 3.5 \end{bmatrix}^{-1} \begin{bmatrix} 0.5 \\ -0.5 \end{bmatrix} = \begin{bmatrix} 0 \\ 0.2 \end{bmatrix} \] \[ \hat{\vec{x}} = \begin{bmatrix} 0 \\ 0.8 \end{bmatrix} + \begin{bmatrix} 0 \\ 0.2 \end{bmatrix} = \begin{bmatrix} 0 \\ 1.0 \end{bmatrix} \]

传感器性能特性





动态范围





定义：传感器测量范围上界和下界的比率，通常用 \(dB\) 为单位。



功率测量：\(10 \log_{10} \left[ \frac{P_{max}}{P_{min}} \right]\)





例如：测量能量从 \(1mW\) 到 \(20W\)，即 \(10 \log_{10} \left[ \frac{20}{0.001} \right] = 43dB\)。



电压测量：\(20 \log_{10} \left[ \frac{U_{max}}{U_{min}} \right]\)





例如：测量电压从 \(1mV\) 到 \(20V\)，即 \(20 \log_{10} \left[ \frac{20}{0.001} \right] = 86dB\)。



注：系数为 20 是因为功率 \(P = U \cdot I = \frac{1}{R}U^2\)，与电压平方成正比。



测量范围





测量上界 - 测量下界。



分辨率





能够测量的被测目标的最小差别。



一般指动态范围的下界。



对于数字传感器，通常指 A/D 的分辨率（如 \(5V/255\) 对应 8 位，\(3600/4096\) 对应 12 位）。



线性度





输入输出信号的映射关系。



若满足 \(f(\alpha x + \beta y) = \alpha f(x) + \beta f(y)\)，则具有线性度。

3. 移动机器人主要传感器工作原理

3.1 光电传感器

工作原理首先把被测量的变化转换成光信号的变化，然后通过光电转换元件变换成电信号。被测量通过对辐射源或者光学通路的影响将待测信息调制到光波上（改变光波的强度、相位、空间分布和频谱分布等），由光电器件将光信号转化为电信号。电信号经后续电路解调分离出被测量信息，实现测量。

组成一般由辐射源、光学通路、光电器件组成。

特性





特点：频谱宽、不受电磁干扰影响、非接触测量、高精度/高分辨力/高可靠性、反应快。



应用：检测、控制领域。

3.2 编码器

编码器主要分为增量式和绝对式两大类。按结构可分为接触式、光电式和电磁式三种（后两种为非接触式）。

3.3 增量式旋转编码器

工作原理





基于莫尔条纹原理。输出电压信号可表示为：\[ U_0 = U_{av} = U_m \cos \left( \frac{2\pi}{W} x \right) = U_m \cos(\theta) \] 其中 \(\theta = \frac{2\pi}{W} x\)。



通过统计脉冲信号的数量来计算旋转的角度，因此输出的位置数据是相对的。

辨向原理及辨向电路





问题：当光栅无论向前或向后移动时，固定点安装的光电元件只能接收到莫尔条纹明暗交替的变化，后续电路产生同样的计数脉冲，无法辨别方向。



解决：必须在测量电路中加入辨向电路。

特点





旋转角度的起始位可以任意设定。



掉电后旋转角度数据会丢失，需要重新复位。

3.4 绝对式光电编码器

测量原理能直接输出某种码制的数码，将角度或直线坐标转换为数字编码。

分辨率

\[ \alpha_{min} = \frac{360^\circ}{2^n} \]

其中 \(n\) 为二进制位数。

格雷码





定义：任意两个相邻数的代码只有一位二进制数不同的 BCD 码，属于可靠性编码（无权数码）。



特点：





反射自补码特性：求反非常方便。



循环特性的单步：消除了随机取数时出现重大误差的可能。在任意两个相邻数之间转换时，只有一个数位发生变化，大大减少了逻辑混淆。

编码转换





二进制数转格雷码： 设 \(G\) 为格雷码，\(B\) 为二进制码：

\[ G(n) = B(n+1) \oplus B(n) \]

其中 \(\oplus\) 表示异或运算（\(a \oplus b = 1\) 当 \(a \neq b\)，否则为 0）。 实例公式：

\[ \begin{cases} G_n = B_n \\ G_i = B_i \oplus B_{i+1}, \quad i < n \end{cases} \]



格雷码转二进制数：

\[ \begin{cases} B_n = G_n \\ B_i = G_i \oplus B_{i+1}, \quad i < n \end{cases} \]

(注：计算时高位左边补 0)

3.5 里程计工作原理

差分移动机器人运动学模型

\[ \begin{cases} \dot{x} = v \cos \theta \\ \dot{y} = v \sin \theta \\ \dot{\theta} = \omega \end{cases} \]

其中线速度 \(v\) 和角速度 \(\omega\) 与左右轮角速度 \(\dot{\phi}_R, \dot{\phi}_L\) 的关系为：

\[ \begin{cases} v = \frac{r(\dot{\phi}_R + \dot{\phi}_L)}{2} \\ \omega = \frac{r(\dot{\phi}_R - \dot{\phi}_L)}{2d} \end{cases} \]

参数说明：





\(r\)：车轮半径



\(d\)：轮距的一半（两轮间距的一半）



\(\dot{\phi}_R, \dot{\phi}_L\)：右轮和左轮的角速度

里程计模型

1. 码盘读数

根据左右轮码盘读数计算机器人的位移增量 \(\Delta s\) 和角度增量 \(\Delta \theta\)：

\[ \begin{cases} \Delta s = \frac{r}{2}(\Delta \phi_R + \Delta \phi_L) \\ \Delta \theta = \frac{r}{2d}(\Delta \phi_R - \Delta \phi_L) \end{cases} \]

其中：





\(r\) 为轮子半径



\(d\) 为轮距的一半



\(\Delta \phi_R, \Delta \phi_L\) 为左右轮转角增量

2. 数值积分方法





欧拉法

\[ \begin{cases} x_{k+1} = x_k + v_k T_s \cos \theta_k \\ y_{k+1} = y_k + v_k T_s \sin \theta_k \\ \theta_{k+1} = \theta_k + \omega_k T_s \end{cases} \]

其中 \(v_k T_s = \Delta s\)，\(\omega_k T_s = \Delta \theta\)。



解析积分法

\[ \begin{cases} x_{k+1} = x_k + \frac{v_k}{\omega_k}(\sin \theta_{k+1} - \sin \theta_k) \\ y_{k+1} = y_k - \frac{v_k}{\omega_k}(\cos \theta_{k+1} - \cos \theta_k) \\ \theta_{k+1} = \theta_k + \omega_k T_s \end{cases} \]

注意：当角速度 \(\omega_k = 0\) 时需要单独处理。



二阶 Runge-Kutta 法

\[ \begin{cases} x_{k+1} = x_k + v_k T_s \cos\left(\theta_k + \frac{\omega_k T_s}{2}\right) \\ y_{k+1} = y_k + v_k T_s \sin\left(\theta_k + \frac{\omega_k T_s}{2}\right) \\ \theta_{k+1} = \theta_k + \omega_k T_s \end{cases} \]

其中 \(\omega_k T_s = \Delta \theta\)，\(\frac{v_k}{\omega_k} = \frac{\Delta s}{\Delta \theta}\)。



里程计误差分析

1. 误差来源





数值积分误差：由离散化时间步长引起。



运动学参数误差：速度不恒定、轮子半径误差等。



打滑：车轮与地面接触不良。

2. 里程计相对增量误区





里程计推算的结果是基于里程开始计算时的坐标系（全局坐标系）。



在定位算法中，上一时刻的定位信息由多传感器融合得到。当前时刻的定位信息通常需要以上一时刻机器人坐标系为参考计算增量，再换算到世界坐标系。



以欧拉法为例的机器人坐标系增量：\[ \begin{cases} \Delta x_k = x_{k-0} = v_{k-1} T_s \\ \Delta y_k = y_{k-0} = 0 \\ \Delta \theta_k = \theta_{k-0} = \omega_{k-1} T_s \end{cases} \]



不确定性表示与误差传导理论

1. 基础统计概念





概率密度函数 (PDF)：曲线下面积为 1，即 \(\int_{-\infty}^{\infty} f(x) dx = 1\)。



期望值：\(\mu = E[X] = \int_{-\infty}^{\infty} x f(x) dx\)。



方差：\(\sigma^2 = \int_{-\infty}^{\infty} (x-\mu)^2 f(x) dx\)。

2. 高斯分布

描述不确定性的最常见概率分布：

\[ f(x) = \frac{1}{\sigma\sqrt{2\pi}} \exp \left( -\frac{(x-\mu)^2}{2\sigma^2} \right) \]

3. 误差传播定律





线性系统 (一维)：若 \(y = f(x) = ax + b\)，且 \(x \sim \mathcal{N}(\mu_x, \sigma_x^2)\)，则：\[ \mu_y = a\mu_x + b, \quad \sigma_y^2 = a^2 \sigma_x^2 \]



线性系统 (多维)：若 \(Y = f(X) = AX + B\)，且 \(X \sim \mathcal{N}(\mu_X, \Sigma_X)\)，则：\[ \Sigma_Y = A \Sigma_X A^T \]



非线性系统：对于多输入多输出系统 \(Y_i = f_i(X_1, \dots, X_n)\)，输出协方差矩阵 \(C_Y\) 为：\[ C_Y = F_X C_X F_X^T \] 其中 \(F_X\) 是雅可比矩阵：\[ F_X = \begin{bmatrix} \frac{\partial f_1}{\partial X_1} & \cdots & \frac{\partial f_1}{\partial X_n} \\ \vdots & \ddots & \vdots \\ \frac{\partial f_m}{\partial X_1} & \cdots & \frac{\partial f_m}{\partial X_n} \end{bmatrix} \]



里程计误差传导模型

1. 映射表达

基于二阶 Runge-Kutta 法，令 \(p' = [x', y', \theta']^T\) 为更新后的位姿：

\[ p' = f(x, y, \theta, \Delta \phi_R, \Delta \phi_L) = \begin{bmatrix} x \\ y \\ \theta \end{bmatrix} + \begin{bmatrix} \frac{r(\Delta \phi_R + \Delta \phi_L)}{2} \cos(\theta_k + \frac{r(\Delta \phi_R - \Delta \phi_L)}{4d}) \\ \frac{r(\Delta \phi_R + \Delta \phi_L)}{2} \sin(\theta_k + \frac{r(\Delta \phi_R - \Delta \phi_L)}{4d}) \\ \frac{r(\Delta \phi_R - \Delta \phi_L)}{2d} \end{bmatrix} \]

2. 输入误差建模

假设左右轮误差独立，且方差正比于转过的距离绝对值：

\[ \Sigma_\Delta = \text{covar}(\Delta \phi_R, \Delta \phi_L) = \begin{bmatrix} k_r |\Delta \phi_R| & 0 \\ 0 & k_l |\Delta \phi_L| \end{bmatrix} \]

3. 误差传导函数

\[ \Sigma_{p'} = \nabla_p f \cdot \Sigma_p \cdot \nabla_p f^T + \nabla_{rl} f \cdot \Sigma_\Delta \cdot \nabla_{rl} f^T \]

其中雅可比矩阵分别为：





状态雅可比 \(F_p = \nabla_p f\)：\[ F_p = \begin{bmatrix} 1 & 0 & -\Delta s \sin(\theta_k + \frac{\Delta \theta}{2}) \\ 0 & 1 & \Delta s \cos(\theta_k + \frac{\Delta \theta}{2}) \\ 0 & 0 & 1 \end{bmatrix} \]



控制输入雅可比 \(F_\Delta = \nabla_{rl} f\)：\[ F_\Delta = \begin{bmatrix} \frac{r}{2} \cos(\theta_k + \frac{\Delta \theta}{2}) - \frac{r}{4d}\Delta s \sin(\theta_k + \frac{\Delta \theta}{2}) & \frac{r}{2} \cos(\theta_k + \frac{\Delta \theta}{2}) + \frac{r}{4d}\Delta s \sin(\theta_k + \frac{\Delta \theta}{2}) \\ \frac{r}{2} \sin(\theta_k + \frac{\Delta \theta}{2}) + \frac{r}{4d}\Delta s \cos(\theta_k + \frac{\Delta \theta}{2}) & \frac{r}{2} \sin(\theta_k + \frac{\Delta \theta}{2}) - \frac{r}{4d}\Delta s \cos(\theta_k + \frac{\Delta \theta}{2}) \\ \frac{r}{2d} & -\frac{r}{2d} \end{bmatrix} \]

4. 误差传导过程可视化





直线运动：垂直于运动方向的误差增长快于运动方向。



曲线运动：误差椭圆不再保持垂直于运动方向。



非高斯模型：误差形状可能不是椭圆。

Line extraction | 3. RANSAC

Algorithm Steps:





Select sample of 2 points at random.



Calculate model parameters that fit the data in the sample.



Calculate error function for each data point.



Select data that supports current hypothesis.



Repeat sampling.



Set with the maximum number of inliers obtained after \(k\) iterations.

How many iterations does RANSAC need?





Ideally, check all possible combinations of 2 points in a dataset of \(N\) points.





Number of all pairwise combinations: \(\frac{N(N-1)}{2}\).



This is computationally unfeasible if \(N\) is too large (e.g., 10,000 points require checking ~50 million combinations).



We can stop after some iterations if we have a rough estimate of the percentage of inliers in our dataset. This can be done probabilistically.

Probability Calculation:





Let \(w\) be the fraction of inliers in the dataset (\(w = \frac{\text{number of inliers}}{N}\)).





\(w = P(\text{selecting an inlier-point out of the dataset})\).



Let \(p\) be the probability of selecting a minimal set of points free of outliers.



Assumption: The 2 points necessary to estimate a line are selected independently.





\(w^2 = P(\text{both selected points are inliers})\).



\(1 - w^2 = P(\text{at least one of these two points is an outlier})\).



Let \(k\) be the number of RANSAC iterations executed so far.





\((1 - w^2)^k = P(\text{RANSAC never selects two points that are both inliers})\).



\(1 - p = (1 - w^2)^k\).

Formula for Iterations:

\[ k = \frac{\log(1 - p)}{\log(1 - w^2)} \]





Knowing the fraction of inliers \(w\), after \(k\) RANSAC iterations we will have a probability \(p\) of finding a set of points free of outliers.



Example: If we want a probability of success \(p = 99\%\) and we know that \(w = 50\%\), then \(k = 16\) iterations. This is dramatically fewer than the number of all possible combinations.



Note: The number of points \(N\) does not influence the estimated number of iterations, only \(w\) does. In practice, we need only a rough estimate of \(w\). More advanced variants of RANSAC estimate the fraction of inliers and adaptively change it on every iteration.

Line extraction | 4. Hough-Transform

Concept:





Points vote for plausible line parameters.



Hough-Transform maps image-space into Hough-space.



Hough-space is a voting accumulator, parameterized with respect to line characteristics.

Mapping:





A line in the image corresponds to a point in Hough space.



A point \((x_0, y_0)\) in the image space maps to a line (or sinusoid in polar coordinates) in the Hough space.



The line containing both \((x_0, y_0)\) and \((x_1, y_1)\) is the intersection of their corresponding curves in Hough space.

Polar Representation:





The \((m, b)\) space has problems: unbounded parameter domain and difficulty representing lines aligned with the axes.



Alternative: Polar representation.



Each point in image space maps to a sinusoid in the \((\rho, \theta)\) parameter space.

Algorithm Steps:





Step 1: Initialize accumulator \(H\) to all zeros.



Step 2: For each edge point \((x, y)\) in the image:





For all \(\theta\) in \([0, 180]\):





Compute \(\rho = x \cos \theta + y \sin \theta\).



\(H(\theta, \rho) = H(\theta, \rho) + 1\).



Step 3: Find the values of \((\theta, \rho)\) where \(H(\theta, \rho)\) is a local maximum.



Step 4: The detected line in the image is given by:\[ \rho = x \cos \theta + y \sin \theta \]

最小二乘直线拟合

Unweighted Least Squares





Point-Line distance:\[ d_i = \rho_i \cos(\theta_i - \alpha) - r \]



If each measurement is equally uncertain, the sum of squared errors is:\[ S = \sum_i d_i^2 = \sum_i (\rho_i \cos(\theta_i - \alpha) - r)^2 \]



Goal: Minimize \(S\) when selecting \((r, \alpha)\). This requires solving the system:\[ \frac{\partial S}{\partial \alpha} = 0, \quad \frac{\partial S}{\partial r} = 0 \]

加权最小二乘直线拟合

Weighted Least Squares





Each sensor measurement may have its own unique uncertainty \(\sigma^2\).



The weighted sum of squared errors is:\[ S = \sum_i w_i d_i^2 = \sum_i w_i (\rho_i \cos(\theta_i - \alpha) - r)^2 \] where \(w_i = \frac{1}{\sigma^2}\).



Goal: Solve \(\frac{\partial S}{\partial \alpha} = 0\) and \(\frac{\partial S}{\partial r} = 0\).

Line Parameters:





The line parameters are given by:\[ \alpha = \frac{1}{2} \arctan \left( \frac{\sum w_i \rho_i^2 \sin 2\theta_i - \frac{2}{\sum w_i} \sum \sum w_i w_j \rho_i \rho_j \cos \theta_i \sin \theta_j}{\sum w_i \rho_i^2 \cos 2\theta_i - \frac{1}{\sum w_i} \sum \sum w_i w_j \rho_i \rho_j \cos(\theta_i + \theta_j)} \right) \] \[ r = \frac{\sum w_i \rho_i \cos(\theta_i - \alpha)}{\sum w_i} \]

Error Propagation Model





The uncertainty of each measurement \(x_i = (\rho_i, \theta_i)\) is described by the covariance matrix:\[ C_{x_i} = \begin{bmatrix} \sigma^2_{\rho_i} & 0 \\ 0 & \sigma^2_{\theta_i} \end{bmatrix} \] (Assuming \(\rho_i, \theta_i\) are independent).



The uncertainty in the line \((r, \alpha)\) is described by the covariance matrix:\[ C_{r\alpha} = \begin{bmatrix} \sigma^2_{\alpha} & \sigma_{\alpha r} \\ \sigma_{r \alpha} & \sigma^2_{r} \end{bmatrix} \]



Define the block diagonal matrix for all points:\[ C_x = \begin{bmatrix} \text{diag}(\sigma^2_{\rho}) & 0 \\ 0 & \text{diag}(\sigma^2_{\theta}) \end{bmatrix} = \begin{bmatrix} \sigma^2_{\rho_1} & 0 & \cdots & 0 & 0 \\ 0 & \sigma^2_{\rho_2} & \cdots & 0 & 0 \\ \vdots & \vdots & \ddots & \vdots & \vdots \\ 0 & 0 & \cdots & \sigma^2_{\theta_{n-1}} & 0 \\ 0 & 0 & \cdots & 0 & \sigma^2_{\theta_n} \end{bmatrix}_{2n \times 2n} \]



Jacobian:\[ F_{\rho\theta} = \begin{bmatrix} \frac{\partial \alpha}{\partial \rho_1} & \frac{\partial \alpha}{\partial \rho_2} & \cdots & \frac{\partial \alpha}{\partial \theta_{n-1}} & \frac{\partial \alpha}{\partial \theta_n} \\ \frac{\partial r}{\partial \rho_1} & \frac{\partial r}{\partial \rho_2} & \cdots & \frac{\partial r}{\partial \theta_{n-1}} & \frac{\partial r}{\partial \theta_n} \end{bmatrix} \]



From Error Propagation Law:\[ C_{\alpha r} = F_{\rho\theta} C_x F^T_{\rho\theta} \]

最小二乘法

基本概念





定义：最小二乘法假设对于给定类型的最佳拟合曲线，是使给定数据集的偏差平方和（最小平方误差）最小的曲线。



数学表达：假设数据点为 \((x_1, y_1), (x_2, y_2), \cdots, (x_n, y_n)\)，其中 \(x\) 是自变量，\(y\) 是因变量。拟合曲线 \(f(x)\) 与每个数据点的偏差（误差）为 \(d_i = y_i - f(x_i)\)。根据最小二乘法，最佳拟合曲线满足：\[ \prod = \sum_{i=1}^n d_i^2 = \sum_{i=1}^n [y_i - f(x_i)]^2 = \min \]

最小二乘直线





使用直线 \(y = f(x) = a + bx\) 来近似给定的数据集（\(n \geq 2\)）。



目标是使最小平方误差最小：\[ \prod = \sum_{i=1}^n [y_i - (a + bx_i)]^2 = \min \]



求解原理：为了获得最小平方误差，未知系数 \(a\) 和 \(b\) 必须使一阶导数为零：\[ \begin{cases} \frac{\partial \prod}{\partial a} = 2 \sum_{i=1}^n [y_i - (a + bx_i)] = 0 \\ \frac{\partial \prod}{\partial b} = 2 \sum_{i=1}^n x_i[y_i - (a + bx_i)] = 0 \end{cases} \]

矩阵形式





回归模型：具有多个解释变量的线性模型为：\[ y_i = \beta_1 + \beta_2 x_{2i} + \beta_3 x_{3i} + \cdots + \beta_k x_{ki} + \epsilon_i \quad (i=1, \cdots, n) \] 为简化符号，将 \(\beta_1\) 写为 \(\beta_1 x_{1i}\)（其中 \(x_{1i} \equiv 1\)）。



矩阵表达：\[ Y = X\beta + \epsilon \] 其中：\[ Y = \begin{pmatrix} y_1 \\ \vdots \\ y_n \end{pmatrix}, \quad X = \begin{pmatrix} x_{11} & x_{21} & \cdots & x_{k1} \\ \vdots & \vdots & \vdots & \vdots \\ x_{1n} & x_{2n} & \cdots & x_{kn} \end{pmatrix}, \quad \beta = \begin{pmatrix} \beta_1 \\ \vdots \\ \beta_k \end{pmatrix}, \quad \epsilon = \begin{pmatrix} \epsilon_1 \\ \vdots \\ \epsilon_n \end{pmatrix} \]

基于最小二乘的优化





由模型可得残差：\(\epsilon = Y - X\beta\)。



残差平方和（关于 \(\beta\) 的代价函数）：\[ S(\beta) = \sum \epsilon_i^2 = \epsilon^T\epsilon = (Y - X\beta)^T(Y - X\beta) \]



最小二乘估计器的目标是 \(\min_{\beta}[S(\beta)]\)。



最优解：令导数为零：\[ \frac{\partial S}{\partial \beta} = -2X^TY + 2X^TX\beta = 0 \] 由此得到正规方程：\[ X^TX\beta = X^TY \implies \beta = (X^TX)^{-1}X^TY \]

基于距离估计的三角定位





问题描述：根据未知节点 \((x, y)\) 到 \(n\) 个参考节点 \(\{(x_1, y_1), \cdots, (x_i, y_i), \cdots, (x_n, y_n)\}\) 的测量距离估计 \(\hat{d}_i\) 来确定位置。这可以表述为一个最小二乘最小化问题。



距离方程：设 \(d_i\) 为到参考节点的正确欧几里得距离：\[ \sqrt{(x_i - x)^2 + (y_i - y)^2} = d_i \] 展开后包含非线性项 \(x^2 + y^2\)：\[ x^2 + y^2 - 2x_i x - 2y_i y = d_i^2 - (x_i^2 + y_i^2) \]



线性化处理：为了将问题表述为最小二乘矩阵形式，需要消除方程中的非线性部分。通过将第 \(i\) 个方程减去第 \(n\) 个方程，得到：\[ 2(x_n - x_i)x + 2(y_n - y_i)y = d_i^2 - d_n^2 + (x_n^2 + y_n^2) - (x_i^2 + y_i^2) \]



矩阵形式：即 \(A\bar{x} = B\)。 其中：\[ A = \begin{pmatrix} 2(x_n - x_1) & 2(y_n - y_1) \\ 2(x_n - x_2) & 2(y_n - y_2) \\ \vdots & \vdots \\ 2(x_n - x_{n-1}) & 2(y_n - y_{n-1}) \end{pmatrix}, \quad \bar{x} = [x \quad y]^T \]

Iterative end-point-fit (迭代端点拟合)：这是该算法的一个略微不同的版本，简单地连接端点进行直线拟合。



2. Line-regression (线性回归)





使用大小为 \(N_f\) 个点的“滑动窗口”。



对每个窗口内的所有点拟合直线段。



3. RANSAC (随机采样一致性)





全称：RANdom SAmple Consensus。



定义：一种通用的、鲁棒的模型拟合算法，适用于存在离群点（即不满足模型的点）的情况。



应用：可应用于任何旨在识别满足预定模型的内点的问题。





典型应用：从 2D 距离数据中提取直线、从 3D 数据中提取平面、特征匹配、运动恢复结构、相机标定、单应性估计等。



特点：





迭代且非确定性。



随着迭代次数的增加，找到无离群点集的概率增加。



缺点：非确定性方法，不同运行之间的结果可能不同。

Line extraction | 3. RANSAC

Algorithm Steps:





Select sample of 2 points at random.



Calculate model parameters that fit the data in the sample.



Calculate error function for each data point.



Select data that supports current hypothesis.



Repeat sampling.



Set with the maximum number of inliers obtained after \(k\) iterations.

How many iterations does RANSAC need?





Ideally, check all possible combinations of 2 points in a dataset of \(N\) points.





Number of all pairwise combinations: \(\frac{N(N-1)}{2}\).



This is computationally unfeasible if \(N\) is too large (e.g., 10,000 points require checking ~50 million combinations).



We can stop after some iterations if we have a rough estimate of the percentage of inliers in our dataset. This can be done probabilistically.

Probability Calculation:





Let \(w\) be the fraction of inliers in the dataset (\(w = \frac{\text{number of inliers}}{N}\)).





\(w = P(\text{selecting an inlier-point out of the dataset})\).



Let \(p\) be the probability of selecting a minimal set of points free of outliers.



Assumption: The 2 points necessary to estimate a line are selected independently.





\(w^2 = P(\text{both selected points are inliers})\).



\(1 - w^2 = P(\text{at least one of these two points is an outlier})\).



Let \(k\) be the number of RANSAC iterations executed so far.





\((1 - w^2)^k = P(\text{RANSAC never selects two points that are both inliers})\).



\(1 - p = (1 - w^2)^k\).

Formula for Iterations:

\[ k = \frac{\log(1 - p)}{\log(1 - w^2)} \]





Knowing the fraction of inliers \(w\), after \(k\) RANSAC iterations we will have a probability \(p\) of finding a set of points free of outliers.



Example: If we want a probability of success \(p = 99\%\) and we know that \(w = 50\%\), then \(k = 16\) iterations. This is dramatically fewer than the number of all possible combinations.



Note: The number of points \(N\) does not influence the estimated number of iterations, only \(w\) does. In practice, we need only a rough estimate of \(w\). More advanced variants of RANSAC estimate the fraction of inliers and adaptively change it on every iteration.

Line extraction | 4. Hough-Transform

Concept:





Points vote for plausible line parameters.



Hough-Transform maps image-space into Hough-space.



Hough-space is a voting accumulator, parameterized with respect to line characteristics.

Mapping:





A line in the image corresponds to a point in Hough space.



A point \((x_0, y_0)\) in the image space maps to a line (or sinusoid in polar coordinates) in the Hough space.



The line containing both \((x_0, y_0)\) and \((x_1, y_1)\) is the intersection of their corresponding curves in Hough space.

Polar Representation:





The \((m, b)\) space has problems: unbounded parameter domain and difficulty representing lines aligned with the axes.



Alternative: Polar representation.



Each point in image space maps to a sinusoid in the \((\rho, \theta)\) parameter space.

Algorithm Steps:





Step 1: Initialize accumulator \(H\) to all zeros.



Step 2: For each edge point \((x, y)\) in the image:





For all \(\theta\) in \([0, 180]\):





Compute \(\rho = x \cos \theta + y \sin \theta\).



\(H(\theta, \rho) = H(\theta, \rho) + 1\).



Step 3: Find the values of \((\theta, \rho)\) where \(H(\theta, \rho)\) is a local maximum.



Step 4: The detected line in the image is given by:\[ \rho = x \cos \theta + y \sin \theta \]

最小二乘直线拟合

Unweighted Least Squares





Point-Line distance:\[ d_i = \rho_i \cos(\theta_i - \alpha) - r \]



If each measurement is equally uncertain, the sum of squared errors is:\[ S = \sum_i d_i^2 = \sum_i (\rho_i \cos(\theta_i - \alpha) - r)^2 \]



Goal: Minimize \(S\) when selecting \((r, \alpha)\). This requires solving the system:\[ \frac{\partial S}{\partial \alpha} = 0, \quad \frac{\partial S}{\partial r} = 0 \]

加权最小二乘直线拟合

Weighted Least Squares





Each sensor measurement may have its own unique uncertainty \(\sigma^2\).



The weighted sum of squared errors is:\[ S = \sum_i w_i d_i^2 = \sum_i w_i (\rho_i \cos(\theta_i - \alpha) - r)^2 \] where \(w_i = \frac{1}{\sigma^2}\).



Goal: Solve \(\frac{\partial S}{\partial \alpha} = 0\) and \(\frac{\partial S}{\partial r} = 0\).

Line Parameters:





The line parameters are given by:\[ \alpha = \frac{1}{2} \arctan \left( \frac{\sum w_i \rho_i^2 \sin 2\theta_i - \frac{2}{\sum w_i} \sum \sum w_i w_j \rho_i \rho_j \cos \theta_i \sin \theta_j}{\sum w_i \rho_i^2 \cos 2\theta_i - \frac{1}{\sum w_i} \sum \sum w_i w_j \rho_i \rho_j \cos(\theta_i + \theta_j)} \right) \] \[ r = \frac{\sum w_i \rho_i \cos(\theta_i - \alpha)}{\sum w_i} \]

Error Propagation Model





The uncertainty of each measurement \(x_i = (\rho_i, \theta_i)\) is described by the covariance matrix:\[ C_{x_i} = \begin{bmatrix} \sigma^2_{\rho_i} & 0 \\ 0 & \sigma^2_{\theta_i} \end{bmatrix} \] (Assuming \(\rho_i, \theta_i\) are independent).



The uncertainty in the line \((r, \alpha)\) is described by the covariance matrix:\[ C_{r\alpha} = \begin{bmatrix} \sigma^2_{\alpha} & \sigma_{\alpha r} \\ \sigma_{r \alpha} & \sigma^2_{r} \end{bmatrix} \]



Define the block diagonal matrix for all points:\[ C_x = \begin{bmatrix} \text{diag}(\sigma^2_{\rho}) & 0 \\ 0 & \text{diag}(\sigma^2_{\theta}) \end{bmatrix} = \begin{bmatrix} \sigma^2_{\rho_1} & 0 & \cdots & 0 & 0 \\ 0 & \sigma^2_{\rho_2} & \cdots & 0 & 0 \\ \vdots & \vdots & \ddots & \vdots & \vdots \\ 0 & 0 & \cdots & \sigma^2_{\theta_{n-1}} & 0 \\ 0 & 0 & \cdots & 0 & \sigma^2_{\theta_n} \end{bmatrix}_{2n \times 2n} \]



Jacobian:\[ F_{\rho\theta} = \begin{bmatrix} \frac{\partial \alpha}{\partial \rho_1} & \frac{\partial \alpha}{\partial \rho_2} & \cdots & \frac{\partial \alpha}{\partial \theta_{n-1}} & \frac{\partial \alpha}{\partial \theta_n} \\ \frac{\partial r}{\partial \rho_1} & \frac{\partial r}{\partial \rho_2} & \cdots & \frac{\partial r}{\partial \theta_{n-1}} & \frac{\partial r}{\partial \theta_n} \end{bmatrix} \]



From Error Propagation Law:\[ C_{\alpha r} = F_{\rho\theta} C_x F^T_{\rho\theta} \]

基于 ICP 的点云匹配算法

ICP 问题描述

ICP（Iterative Closest Point）用于在数据关联未知的情况下，估计两组点云之间的位姿变换。

基本流程：





计算最近点集



计算变换矩阵



更新变换矩阵



计算目标函数并进行阈值判断

ICP 的迭代效果通常表现为：随着迭代次数增加，源点云逐步与目标点云对齐。

最近点集的定义

设：





点集 \(P\) 为传感器检测数据点集，包含 \(N_p\) 个点：

\[ P = \{ \vec{p}_i \mid i = 1, \cdots, N_p \} \]



点集 \(X\) 为目标点集，包含 \(N_x\) 个点：

\[ X = \{ \vec{x}_i \mid i = 1, \cdots, N_x \} \]

某个数据点 \(\vec{p}_i \in P\) 到点集 \(X\) 的几何距离定义为：

\[ d(\vec{p}_i, X) = \min_{\vec{x} \in X} \| \vec{x} - \vec{p}_i \| \]

令 \(\vec{y}_i \in X\) 为 \(\vec{p}_i\) 的最近点，则满足：

\[ d(\vec{p}_i, \vec{y}_i) = d(\vec{p}_i, X) \]

因此最近点集 \(Y\) 定义为：

\[ Y = C(P, X) = \{ (\vec{p}_i, \vec{y}_i) \mid d(\vec{p}_i, \vec{y}_i) = d(\vec{p}_i, X), \vec{p}_i \in P, \vec{y}_i \in X, i = 1, \cdots, N_p \} \]

数据预处理：点云采样

采样的目的





减少计算量
原始点云数据量通常很大，可能达到数万甚至数百万点，直接处理全部点会导致计算开销过高。



降低噪声干扰
采样可以筛选更具代表性的点，如关键点或特征点，减弱噪声对匹配过程的影响，提高配准精度。



避免冗余与局部过拟合
密集点云中存在大量相似点，若全部参与匹配，可能使算法陷入局部最优。采样可以保留关键特征，提高鲁棒性。

最近点集计算中的点集匹配方法

常见匹配方式：





Closest Point Matching



Normal Shooting Matching



Point-to-Plane Matching



Projection Matching



使用 kd-trees 或 oc-trees 的匹配方法

注意：





数据关联方法对 ICP 的收敛性和运行速度影响最大。

1. Closest Point Matching（CPM）

最近点集仍定义为：

\[ Y = C(P, X) = \{ (\vec{p}_i, \vec{y}_i) \mid d(\vec{p}_i, \vec{y}_i) = d(\vec{p}_i, X), \vec{p}_i \in P, \vec{y}_i \in X, i = 1, \cdots, N_p \} \]

特点：





一般较稳定



但速度较慢



通常需要预处理

2. Normal Shooting Matching

基本思路：





沿着法线方向投影，并与另一点集求交

特点：





对平滑结构略优于最近点匹配



对噪声较大或结构复杂的场景效果较差

3. Point-to-Plane Matching

基本思路：

Point-to-Plane 方法中，对于源曲面上的一点 \(\vec{p}\)，先在目标曲面上寻找与其对应的最近点 \(\vec{q}\)。搜索过程依据源曲面上点 \(\vec{p}\) 的切平面法线方向，找到目标曲面上的交点 \(\vec{q}'\)。然后根据目标曲面上 \(\vec{q}'\) 点的切平面，求源曲面上点 \(\vec{p}\) 到该切平面的垂足 \(\vec{q}\)，并据此构建匹配关系。

4. Projection Matching

基本思路：

Point-to-Projection 是一种快速配准方法。设 \(O_q\) 为扫描目标曲面的透视点位置。对于源曲面上的点 \(\vec{p}\)，沿 \(O_q\) 指向 \(\vec{p}\) 的投影线，与目标曲面的交点 \(\vec{q}\) 作为对应最近点。

特点：





每次迭代的配准效果略差



但每次迭代的速度比最近点匹配快 \(1 \sim 2\) 个数量级

Point-to-Distribution Matching

Point-to-Point 匹配

采用欧式距离度量：

\[ \hat{R} = \arg\max_R \sum_{i=1}^{n} w_i \| (R p_i + t) - q_i \|^2 \]

Point-to-Distribution 匹配

采用马氏距离度量。

设：

\[ \hat{b}_i = T \hat{a}_i \Rightarrow d_i = \hat{b}_i - T \hat{a}_i \]

则有：

\[ d_i \sim \mathcal{N}(\hat{b}_i - T \hat{a}_i,\ \Sigma_b + T \Sigma_a T^{\top}) \]

进一步可写为：

\[ \mathcal{N}(0,\ \Sigma_b + T \Sigma_a T^{\top}) \]

优化目标为：

\[ \hat{T} = \arg\max_T \prod_i p(d_i) = \arg\max_T \sum_i \log(p(d_i)) \]

等价形式为：

\[ \hat{T} = \arg\max_T \sum_{i=1}^{n} d_i^{\top} (\Sigma_b + T \Sigma_a T^{\top})^{-1} d_i \]

要点：





Point-to-Point 使用欧式距离



Point-to-Distribution 使用马氏距离



后者能够考虑点分布的不确定性与协方差结构

总结





ICP 是一种用于计算不同扫描结果之间位移关系的强大算法。



ICP 的主要难点在于正确确定数据关联关系。



一旦数据关联正确，变换矩阵可以通过 SVD 高效求解。

相关概念

先验估计、先验估计误差及先验估计方差 \(\hat{x}^-_k, e^-_k, P^-_k\)





定义 \(\hat{x}^-_k \in \mathbb{R}^n\) 为第 \(k\) 步的先验状态估计，基于过程转移方程和第 \(k\) 步之前的状态先验 \(x_{k-1}\) 得出。



定义先验估计误差为 \(e^-_k \equiv x_k - \hat{x}^-_k\)。



先验估计误差协方差定义为 \(P^-_k = E[e^-_k e^{-T}_k]\)。

后验估计、后验估计误差及后验估计方差 \(\hat{x}_k, e_k, P_k\)





定义 \(\hat{x}_k \in \mathbb{R}^n\) 为第 \(k\) 步的后验状态估计，结合了测量值 \(z_k(k)\) 和先验状态估计 \(\hat{x}^-_k\)。



定义后验估计误差为 \(e_k \equiv x_k - \hat{x}_k\)。



后验估计误差协方差定义为 \(P_k = E[e_k e^T_k]\)。

优化策略角度下的卡尔曼滤波算法

在推导卡尔曼滤波方程时，我们的目标是找到一个方程，将后验状态估计 \(\hat{x}_k\) 计算为先验估计 \(\hat{x}^-_k\) 和实际测量 \(z_k\) 与测量预测 \(H\hat{x}^-_k\) 之间加权差值的线性组合，如下所示：

\[ \hat{x}_k = \hat{x}^-_k + K(z_k - H\hat{x}^-_k) \quad (4) \]

其中：





\(K \in \mathbb{R}^{n \times m}\)：增益或混合因子。



\((z_k - H\hat{x}^-_k)\)：测量新息或残差。

目标函数：

\[ \arg \min_K P_k \quad (5) \]

推导过程：

\[ \begin{aligned} P_k &= E[e_k e^T_k] = E[(x_k - \hat{x}_k)(x_k - \hat{x}_k)^T] \\ &= E[\{x_k - [\hat{x}^-_k + K(z_k - H\hat{x}^-_k)]\} \{x_k - [\hat{x}^-_k + K(z_k - H\hat{x}^-_k)]\}^T] \\ &= E[((x_k - \hat{x}^-_k) - K(Hx_k + v_k - H\hat{x}^-_k)) ((x_k - \hat{x}^-_k) - K(Hx_k + v_k - H\hat{x}^-_k))^T] \\ &= E[((x_k - \hat{x}^-_k) - K(H(x_k - \hat{x}^-_k) + v_k)) ((x_k - \hat{x}^-_k) - K(H(x_k - \hat{x}^-_k) + v_k))^T] \\ &= E[(e^-_k - K(He^-_k + v_k))(e^-_k - K(He^-_k + v_k))^T] \\ &= E[((I - KH)e^-_k - Kv_k)((I - KH)e^-_k - Kv_k)^T] \\ &= E[(I - KH)e^-_k e^{-T}_k (I - KH)^T + Kv_k v^T_k K^T - Kv_k e^{-T}_k (I - KH)^T - (I - KH)e^-_k v^T_k K^T] \\ &= (I - KH) \underbrace{E[e^-_k e^{-T}_k]}_{P^-_k} (I - KH)^T + K \underbrace{E[v_k v^T_k]}_{R} K^T - K \underbrace{E[v_k e^{-T}_k]}_{0} (I - KH)^T - (I - KH) \underbrace{E[e^-_k v^T_k]}_{0} K^T \\ &= (I - KH)P^-_k(I - KH)^T + KRK^T \end{aligned} \]

最优值求取：

目标函数：

\[ \arg \min_K P_k = (I - KH)P^-_k(I - KH)^T + KRK^T \]

对 \(K\) 求导并令其为 0：

\[ \frac{\partial P_k}{\partial K} = -2P^-_k H^T + 2KHP^-_k H^T + 2KR = 0 \Rightarrow K = P^-_k H^T (HP^-_k H^T + R)^{-1} \]

注意：





当测量误差协方差 \(R\) 趋近于 0 时，\(\lim_{R \to 0} K = H^{-1}\)。



当先验估计误差协方差 \(P^-_k\) 趋近于 0 时，\(\lim_{P^-_k \to 0} K = 0\)。

\[ \begin{bmatrix} u_k \\ v_k \end{bmatrix} = \begin{bmatrix} H_x & 0 \\ 0 & H_y \end{bmatrix} \begin{bmatrix} x_k \\ y_k \end{bmatrix} + \begin{bmatrix} \tilde{u}_k \\ \tilde{v}_k \end{bmatrix} \]

State Transition \(A = \begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix}\)



Process Noise Covariance \(Q = E[\bar{w} \times \bar{w}^T] = \begin{bmatrix} q_{xx} & 0 \\ 0 & q_{yy} \end{bmatrix}\)

Action and perception updates

In robot localization, we distinguish two update steps:





Action update:





The robot moves and estimates its position through its proprioceptive sensors. During this step, the robot uncertainty grows.



Perception update:





The robot makes an observation using its exteroceptive sensors and correct its position by opportunely combining its belief before the observation with the probability of making exactly that observation. During this step, the robot uncertainty shrinks.

\[ \hat{x}_t = f(x_{t-1}, u_t), \quad \hat{P}_t = F_x \cdot P_{t-1} \cdot F_x^T + F_u \cdot Q_t \cdot F_u^T \]

Observation





The second step is to obtain the observation \(Z\) (measurements) from the robot's sensors at the new location.



The observation usually consists of a set \(n_0\) of single observations \(z_j\) extracted from the different sensors signals. It represents features like lines, doors or any kind of landmarks.



The parameters of the targets are usually observed in the sensor frame \(\{S\}\).



Therefore the observations have to be transformed to the world frame \(\{W\}\) or the measurement prediction have to be transformed to the robot frame \(\{R\}\).

Measurement Prediction





In the next step we use the predicted robot position \(\hat{x}_t\) and the features \(m_j\) in the map \(M\) to generate multiple predicted observations \(\hat{z}^t_j\).



They have to be transformed into the sensor frame: \(\hat{z}^t_j = h_j(\hat{x}_t, m_j)\).



We can now define the measurement prediction as the set containing all \(n_j\) predicted observations: \(\hat{Z} = \{\hat{z}^t_j | 1 \le j \le n_j\}\).



The function \(h_j\) is mainly the coordinate transformation between the world \(\{W\}\) frame and the sensor/robot frame \(\{R\}\).



For prediction, only the walls that are in the field of view of the robot are selected. This is done by linking the individual lines to the nodes of the path.

基于卡尔曼滤波定位算法流程

1. 预测模型 (先验估计): 里程计模型 (世界坐标系下)

\[ \begin{cases} x_{k+1} = x_k + \Delta s \cos(\theta_k + \frac{\Delta \theta}{2}) \\ y_{k+1} = y_k + \Delta s \sin(\theta_k + \frac{\Delta \theta}{2}) \\ \theta_{k+1} = \theta_k + \Delta \theta \end{cases} \]

其中，码盘读数为:

\[ \begin{cases} \Delta s = \frac{r}{2}(\Delta \phi_R + \Delta \phi_L) \\ \Delta \theta = \frac{r}{2d}(\Delta \phi_R - \Delta \phi_L) \end{cases} \]

2. 先验估计误差模型: 里程计误差传导 (非线性)

\[ \Sigma'_p = \nabla_p f \cdot \Sigma_p \cdot \nabla_p f^T + \nabla_{rl} f \cdot \Sigma_\Delta \cdot \nabla_{rl} f^T \]

其中:

\[ F_p = \nabla_p f = \begin{bmatrix} \frac{\partial f}{\partial x} & \frac{\partial f}{\partial y} & \frac{\partial f}{\partial \theta} \end{bmatrix} = \begin{bmatrix} 1 & 0 & -\Delta s \sin(\theta_k + \frac{\Delta \theta}{2}) \\ 0 & 1 & \Delta s \cos(\theta_k + \frac{\Delta \theta}{2}) \\ 0 & 0 & 1 \end{bmatrix} \] \[ F_\Delta = \nabla_{rl} f = \begin{bmatrix} \frac{\partial f}{\partial \Delta \phi_R} & \frac{\partial f}{\partial \Delta \phi_L} \end{bmatrix} = \begin{bmatrix} \frac{r}{2} \cos(\theta_k + \frac{\Delta \theta}{2}) - \frac{r}{4d}\Delta s \sin(\theta_k + \frac{\Delta \theta}{2}) & \frac{r}{2} \cos(\theta_k + \frac{\Delta \theta}{2}) + \frac{r}{4d}\Delta s \sin(\theta_k + \frac{\Delta \theta}{2}) \\ \frac{r}{2} \sin(\theta_k + \frac{\Delta \theta}{2}) + \frac{r}{4d}\Delta s \cos(\theta_k + \frac{\Delta \theta}{2}) & \frac{r}{2} \sin(\theta_k + \frac{\Delta \theta}{2}) - \frac{r}{4d}\Delta s \cos(\theta_k + \frac{\Delta \theta}{2}) \\ \frac{r}{2d} & -\frac{r}{2d} \end{bmatrix} \]

3. 观测模型: 激光定位算法 (ICP: 确定匹配关系, SVD: 确定机器人位姿)给定两个在 2 维空间中对应的点集合 \(P = \{p_1, p_2, \cdots, p_n\}\) 和 \(Q = \{q_1, q_2, \cdots, q_n\}\):





加权平均:\[ \hat{p} = \frac{\sum_{i=1}^n w_i p_i}{\sum_{i=1}^n w_i}, \quad \hat{q} = \frac{\sum_{i=1}^n w_i q_i}{\sum_{i=1}^n w_i} \] 其中 \(w_i\) 为权重参数，可根据激光测量距离取 \(w_i = 1/\sigma_i(\rho_i)\)。



去中心化:\[ x_i := p_i - \hat{p}, \quad y_i := q_i - \hat{q} \] 构造矩阵 \(W = \text{diag}(w_1, \cdots, w_n), X = [x_1, x_2, \cdots, x_n], Y = [y_1, y_2, \cdots, y_n] \in \mathbb{R}^{2 \times n}\)。



构造 SVD 矩阵: 令 \(S = X W Y^T = U \Sigma V^T\)，由 SVD 原理，求取 \(U, V\) 单位正交阵。



求取旋转矩阵 \(R\): \(R = V U^T\)



求取平移矩阵 \(t\): \(t = \hat{q} - R \hat{p}\)

4. 观测误差模型: SVD 定位误差模型最小的匹配误差为:

\[ \arg \min \sum_{i=1}^n w_i \| (R p_i + t) - q_i \|^2 = \sum_{i=1}^n w_i x_i^T x_i + \sum_{i=1}^n w_i y_i^T y_i - 2 \sum_{i=1}^n \sigma_i \]

其中:





\(w_i\) 为权重参数，可根据激光测量距离取 \(w_i = 1/\sigma_i(\rho_i)\)。



\(\rho_i\) 为激光测距方差，可对激光雷达离线标定获得。



\(x_i := p_i - \hat{p}\) 为地图特征去中心化后的点。



\(y_i := q_i - \hat{q}\) 为激光雷达坐标系下识别的特征去中心化后的点。

5. 基于观测的后验估计 (对先验估计的修正):





卡尔曼增益 \(K\):\[ K = P^-_k H^T (H P^-_k H^T + R)^{-1} \]



后验估计 \(\bar{x}_k\):\[ \bar{x}_k = \bar{x}^-_k + K(\bar{z}_k - H\bar{x}^-_k) \]



后验估计误差 \(P_k\):\[ P_k = (I - KH)P^-_{k-1} \]

基于卡尔曼滤波定位算法总结





基于卡尔曼滤波定位算法仅能处理位置跟踪问题。



根据里程计推演信息，可得到对机器人当前位姿的估计。



根据对机器人当前位姿估计，在地图中进行匹配搜索，避免 ICP 陷入局部最优，导致定位失败。



激光定位精度一般在 2-3cm，使用基于卡尔曼滤波定位算法融合里程计后，定位精度可达 5mm 左右。



严重依赖于匹配精度，如果出现匹配错误，则机器人定位失败。



无法判断定位失败。



无法从定位失败中恢复。



收敛速度受初始状态误差，以及协方差阵的精度影响较大。



无法进行全局定位。
