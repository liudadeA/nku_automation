1. 运动规划(Motion Planning)
◼何为运动规划：
运动规划是一个过程，根据所给定的地图，寻找从起始状
态到目标状态的运动序列。运动规划常常需要在运动受到
约束的条件下找到最优解。
——Wikipedia 
◼需求：
安全性：规避障碍物
可达性：从起点到终点的连通域
光滑性：能量优化，运行的平稳性，舒适性
可执行性：
✓机器人在动力学约束(Kinodynamic feasibility)下的运行可行性
✓机器人执行单元的性能约束：速度，加速度，加加速度(Jerk)

1.2 移动机器人路径规划方法
◼图搜索的路径规划算法（算法完备）
如果在起始点和目标点间有路径解存在那么一定可以得到解，如果得不到解那么一定说明
没有解存在。
完备的算法的优势在与它对于解的捕获能力是完全的，但是由此产生的缺点就是算法复杂

◼基于采样的路径规划算法（概率完备）

一定密度的粒子来抽象实际地图辅助规划。
基于采样的算法速度较快，但是生成的路径代价（可理解为长度）较完备的算法高，而且
会产生“有解求不出”的情况
这样的算法一般在高维度的规划问题中广泛运用

2.2 图的构建（7）——搜索树
◼一般来说，从起点开始生长树结构，直至找到一个解决方案（到达目标的路径）。
◼Expanding a node refers to adding children to the tree, pushing them onto 
the open set
◼Try to expand as few tree nodes as possible
◼Open set maintains a list of frontier (unexpanded) plans
Keeps track of what nodes to expand next
Often stored as a priority queue
For each node in the open list, we know of at least one path to it from the start
◼Closed set：用于跟踪已扩展的节点。
对于Closed set中的每个节点，已经找到了从起点到该节点的成本最低路径。

ARA*算法：
◼权重A*算法通过加大启发函数的权重（膨胀系数𝜖），提升算法效率
不满足A*算法中的可采纳性(admissible）
只能得到局部最优解，无法获得全局最优解
◼A*可以得到全局最优解，但算法效率低，很难保证实时性
◼ARA*算法：任意时间法（Anytime algorithm） + 权重A*（Weighted A*）兼顾效率与性能
◼任意时间法（Anytime algorithm）：
由Shlomo Zilberstein以及Stuart Russell提出
普适性算法：一种策略、思路
在很短的时间内先得出一个次优的解法，然后再对这个解法进行不断的优化。
✓膨胀系数𝜖先取一个较大值，提升算法速度，然后不断降低，直至为1，或到达给定时间
◼如何降低迭代过程中的重复计算：
引入INCONS表：防止已经进入CLOSED表的节点不再进入OPEN表中进行二次扩展

3.2.3 D*算法思路
◼算法起始，初始化地图上的所有节点的tag为NEW，k函数和h函数为0；
◼将目标点G放入OPEN表中，从目标节点开始进行路径规划。直到机器人当前所
在的节点X被从OPEN列表中移除，规划完毕。
◼机器人沿着当前已经规划好的路径序列前进，直到到达目标节点或者检测到地
图和实际环境不匹配。
◼当检测到地图和环境有出入的时候，调用MC函数，修改地图上的路径代价信息，
并通过OPEN表将地图变化的信息传播出去，直到机器人所在的当前节点的路
径调整完毕后，机器人沿着新的路径继续前进，直到到达终点。
◼算法一开始的路径规划是迪杰斯特拉算法，并且是从终点开始的迪杰斯特拉算
法。当第一次迪杰斯特拉算法过后，保留原始的节点状态，机器人开始运行，
并在检查到路径代价错误时自动调整地图。

3.5 D*-Lite算法
◼D*-lite算法是LPA*算法的动态形式，即将目标点作为规划起点，将机器人
当前位置作为规划终点
◼LPA*算法只能适用于给定两点的动态地图导航，而D*-lite算法则可直接用

◼D*-lite算法从算法逻辑上并不是D*算法的改进版本，它被作者称为D* like
算法。相较于D*算法，代码量更小，逻辑更容易理解，更易于学习，且在
实验中，D*-lite算法的效率至少和D*算法的效率是一样的。
