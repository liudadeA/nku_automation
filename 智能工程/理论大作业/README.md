# 叉车式移动机器人完整仿真系统

## 项目概述

本项目实现了一个完整的叉车式移动机器人自主导航仿真系统，包括运动学建模、控制算法设计、里程计模型、点云处理和卡尔曼滤波定位等核心模块，并生成了符合学术规范的研究报告。

## 核心功能模块

### 1. 系统建模（第二章）
- **瞬心法建模**：通过分析瞬时旋转中心推导运动学方程
- **运动约束法建模**：利用轮子非完整约束条件建立约束方程
- **两种方法对比**：验证模型的一致性和正确性

### 2. 控制算法设计（第三章）
- **Lyapunov控制器**：基于Lyapunov稳定性理论设计轨迹跟踪控制器
- **控制参数优化**：调节控制增益实现稳定跟踪
- **仿真验证**：通过仿真实验验证控制器性能

### 3. 里程计模型（第四章）
- **位姿更新方程**：建立里程计的运动学模型
- **误差传导模型**：推导雅可比矩阵和协方差传播
- **误差特性分析**：分析里程计误差的累积特性

### 4. 点云直线提取（第五章）
- **Split-and-Merge算法**：递归分割点云提取直线特征
- **直线拟合**：使用SVD方法进行最小二乘拟合
- **参数优化**：调整距离阈值和最小点数等参数

### 5. ICP点云配准（第六章）
- **迭代最近点算法**：实现点云之间的刚体变换估计
- **SVD变换估计**：通过奇异值分解求解最优变换
- **收敛判断**：设置合理的收敛阈值

### 6. 卡尔曼滤波定位（第七章）
- **扩展卡尔曼滤波**：实现非线性系统的状态估计
- **预测步骤**：基于运动模型进行状态预测
- **更新步骤**：融合激光雷达观测信息
- **雅可比矩阵计算**：推导运动和观测雅可比矩阵

## 仿真参数配置

### 机器人参数
- **轮A（固定轮）**：α = -π/2, β = π, l = 1.0 m
- **轮B（固定轮）**：α = π/2, β = 0, l = 1.0 m
- **转向轮（受控）**：α = 0, β = π/2, l = 2.0 m

### 仿真参数
- **仿真时间**：40.0 s
- **时间步长**：0.05 s
- **激光雷达范围**：15.0 m
- **地标数量**：30个
- **环境尺寸**：20.0 m

### 噪声模型
- **速度噪声**：σ_v = 0.05 m/s
- **转向角噪声**：σ_δ = 0.02 rad
- **距离观测噪声**：σ_r = 0.1 m
- **角度观测噪声**：σ_φ = 0.05 rad
