# 最优控制复习资料（第六章）

这份详细的复习资料根据《最优控制》第六章内容整理。为了帮你应对考试，我不仅还原了公式，还增加了**通俗的逻辑解释**，并补充了你提到的**最大值原理**和**Bang-Bang控制**（这些通常在变分法之后，作为解决有约束问题的核心工具）。

## 第一部分：最优控制问题的“底座” (6.1节)

### 1. 最优控制的三要素 (通俗理解：游戏规则)

- **数学模型** ($\dot{x} = f(x, u, t)$)：这描述了“物理定律”。就像赛车性能，你踩多少油门（控制量 $u$），速度和位置（状态量 $x$）会怎么变。

- **容许控制** ($u \in U$)：这是“物理极限”。油门不能踩进地板里，方向盘不能转 3600 度。控制量必须在规定范围内。

- **性能指标** ($J$)：这是“评分标准”。是追求速度最快？还是省油？还是过程平稳？

### 2. 典型的六大问题 (常考名词解释/填空)

- **最小时间问题**：$J = \int dt = t_f$。目标是“快”。

- **最小能量问题**：$J = \int u^2 dt$。目标是“省电/省力”，平方项是为了惩罚大强度的控制。

- **最省燃料问题**：$J = \int |u| dt$。目标是“节油”，常见于航天器。

- **状态调节器**：让状态偏离平衡点的误差积分最小。目标是“稳”。

- **跟踪问题**：让系统紧跟给定轨迹。目标是“准”。

## 第二部分：古典变分法 (6.2节 - 处理无约束问题)

### 1. 核心思想：变分 ($\delta$)

**通俗解释**：想象一条最优路径，如果你稍微把它“抖动”一下（这就是变分 $\delta x$），它的总得分 $J$ 不应该变得更好。在数学上，这意味着“泛函的一阶导数（变分）等于0”。

### 2. 欧拉-拉格朗日方程 (E-L Equation)

**公式**：$\frac{\partial f}{\partial x} - \frac{d}{dt} (\frac{\partial f}{\partial \dot{x}}) = 0$。

**通俗解释**：这是判断一条线是否是“最强候选人”的判据。只要是无约束的最优路径，必须满足这个微分方程。

### 3. 横截条件 (Transversality Condition)

**重点难点**：如果终点不固定（自由端点）或者终点必须在某条线上（可动边界），我们就缺少边界条件来解方程。

**通俗解释**：横截条件是“补丁”。它利用性能指标在终点的特性，强行给出一个边界方程（如 $\frac{\partial f}{\partial \dot{x}}|_{t_f} = 0$），让你能解出微分方程的常数。

## 第三部分：庞特里金最大值原理 (解决控制受限的关键)

**为什么需要它？**
变分法要求对 $u$ 求导，但如果 $u$ 有约束（如 $|u| \le 1$），最优解往往落在边界上（导数不为 0）。最大值原理就是为了处理这种“踩到底”的情况。

### 1. 哈密顿函数 (Hamiltonian, $H$)

**公式**：$H = L(x, u, t) + \lambda^T f(x, u, t)$。

**通俗解释**：$L$ 是当下的代价，$\lambda$ 是“影子价格”（协状态），$f$ 是未来的趋势。$H$ 代表了“当前付出”与“未来收益”的总和。

### 2. 正则方程 (Canonical Equations)

- 状态方程：$\dot{x} = \frac{\partial H}{\partial \lambda}$
- 协状态方程：$\dot{\lambda} = -\frac{\partial H}{\partial x}$
- **控制要求**：最优控制 $u^*$ 必须使 $H$ 达到最大（或极小，取决于定义）。

## 第四部分：Bang-Bang控制 (开关控制)

### 1. 概念解释

**通俗解释**：当控制量 $u$ 在性能指标中是线性的（例如最省燃料或最短时间），哈密顿函数 $H$ 对 $u$ 的偏导数是一个常数或仅与时间有关。为了让 $H$ 最大，你只能把 $u$ 推到极限位置（要么正最大，要么负最大）。

**形象理解**：就像电灯开关，没有中间调光，要么全开，要么全关。

### 2. 切换函数

系统会根据一个函数（切换函数）的正负号，在 $U_{max}$ 和 $U_{min}$ 之间瞬间切换。

## 第五部分：经典例题求解 (复习核心)

### 例题 1：无约束状态调节器 (例6.4)

**题目**：$\dot{x} = -x + u, x(0)=1, x(t_f)=0$。求 $u$ 使 $J = \frac{1}{2} \int_0^{t_f} (x^2 + u^2) dt$ 最小。

**求解步骤**：

1. **代换**：由状态方程得 $u = \dot{x} + x$。

2. **构造泛函**：$J = \int \frac{1}{2}(x^2 + (\dot{x}+x)^2) dt$。

3. **应用E-L方程**：对 $f = x^2 + \dot{x}^2 + 2x\dot{x} + x^2$ 求导，得到 $\ddot{x} - 2x = 0$。

4. **解方程**：特征根为 $\pm\sqrt{2}$。解为 $x(t) = Ae^{\sqrt{2}t} + Be^{-\sqrt{2}t}$。

5. **代入边界**：利用 $x(0)=1$ 和 $x(t_f)=0$ 解出 $A$ 和 $B$。

### 例题 2：登月舱软着陆 (Bang-Bang控制原型)

**题目**：推力 $u \in [0, U_{max}]$，要求燃料最少 ($J = m(t_f)$ 最大)。

**求解逻辑**：
1. 列出哈密顿函数 $H$。
2. 发现 $H$ 是 $u$ 的线性函数：$H = (\dots)u + (\dots)$。

**结论**：为了让燃料最省，发动机在大部分时间应该是关闭的（$u=0$），只在最后接近月球表面时开启最大推力（$u=U_{max}$）进行缓冲。这就是典型的 Bang-Bang 控制。

## 考前复习建议：

1. **分清边界条件**：如果是“自由端点”，一定要写出横截条件 $\frac{\partial f}{\partial \dot{x}}|_{t_f}=0$，这是拿高分的关键。

2. **熟记哈密顿构造**：看到“受限”、“最大值原理”字眼，立刻写出 $H = L + \lambda f$。

3. **理解线性系统**：只要控制量 $u$ 在方程里是一次项，大概率会出现 Bang-Bang 控制。
